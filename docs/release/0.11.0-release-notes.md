# NaruServe 0.11.0

English | [한국어](0.11.0-release-notes.ko.md)

0.11.0 adds the built-in auth/RBAC module `com.snoworca.naruserve.utils.auth` to `naruserve-api`. It is optional: an app that does not build an `Auth` behaves as in 0.10.0.

## Auth and RBAC

- `Auth.builder(secret)...build()` and `app.use(auth)` add JWT login, refresh, logout, the profile and password endpoints under `/auth`, and default deny for every other path; `.permit(...)` and `.permitPrefix(...)` open public paths.
- Roles and scopes come from a `RolePolicy` (or a `RoleStore`); guards are `auth.require(scope)`, `auth.requireRole(role)`, `auth.check(rule)` and `auth.authenticated()`. Groups with parent groups confer roles through a `GroupStore`.
- Admin endpoints under `/auth/admin` manage users, groups and, with `.apiKeys(store)`, API keys; personal API keys are issued under `/auth/me/apikeys`.
- Persistence is behind SPIs (`UserStore`, `RefreshTokenStore`, `LoginThrottle`, `DeviceTrust`, `GroupStore`, `ApiKeyStore`); in-memory and file stores ship, with `AuthFileKey` encryption of file secrets. `AuthTesting.verifyUserStore` checks an app's own store.
- A startup doctor stops a PROD start on a weak secret, an unencrypted file store, CORS registered after auth and similar mistakes, and logs a WARN for typos such as undeclared roles and scopes. `AuthMode.DEV` relaxes the PROD rules for local work.
- Error answers are JSON and name the fix: a wrong path or method, a misplaced token or key, an unknown body field, a refresh token used as an access token. In PROD a final error layer that auth appends at start answers an app exception as JSON without a stack trace.

## Core

- `Installable`: `app.use(x)` and `app.use("/", x)` call `x.install(app)` when `x` implements it; `app.use(auth)` is the same as `auth.install(app)`. A path use other than `""` or `"/"` throws `IllegalArgumentException`.
- `app.registrations()` lists what the app registered, in order, and `app.onRegistration(listener)` observes new registrations.
- `app.trustProxyHops(n)` and `app.trustProxyCidrs(...)` trust a proxy by hop count or address range.

## Upgrading from 0.10.0

Change the version to **0.11.0**; nothing else is required. `app.use("/", x)` with an `Installable` now installs it instead of adding it as plain middleware; only `auth` implements `Installable` in the shipped modules. Runtime dependencies are unchanged.

## Installation and verification

All modules use `com.snoworca.naruserve` and version **0.11.0**. See the [README installation instructions](../../README.md#install) and the [auth guide](../api/en/auth.md).

The core targets Java 8; source builds use JDK 17 and Gradle 8.14.3. API 21 signature checks run in the build; they are static evidence, not a device run.
