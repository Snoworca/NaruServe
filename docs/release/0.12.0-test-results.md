# 0.12.0 verification record

Current source references belong to the 0.12.0 profile, which first ships the raw access API of `naruserve-api` and the reverse proxy module `NaruServe-proxy` (`com.snoworca.naruserve:naruserve-proxy`). The 0.11.0, 0.10.0 and dated v1/0.9.0 records remain unchanged.

Complete Java 17 and actual Java 8 (Zulu 8) builds pass at the release commit, with 4,848 tests each and zero failures/errors/skips. The local staging check finds the eleven artifactIds at 0.12.0, and the release SBOM run writes one CycloneDX file per published module. Publication to Maven Central (signing, upload, public-byte verification), the GitHub release and the release tag are not part of this record and have not run.
