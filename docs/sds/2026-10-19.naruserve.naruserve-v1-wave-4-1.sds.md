## Acceptance Contracts

- SDS-AC-1 (IR-APP-001 AC-1): WHEN build() is called twice on one Builder THE SYSTEM SHALL return two distinct DefaultRestApp instances in state NEW sharing the configured adapter, codec and logger → `Builder.build`, `RestApp.builder`
- SDS-AC-2 (IR-APP-001 AC-2): WHEN build() runs with no adapter or no codec THE SYSTEM SHALL throw IllegalStateException naming httpAdapter(...) or jsonCodec(...), the adapter checked first; a null setter argument throws NullPointerException at the setter → `Builder.build`, `Builder.httpAdapter`
- SDS-AC-3 (IR-APP-001 AC-3): WHEN logger(...) was never called THE SYSTEM SHALL create one new ConsoleLogger per build() → `Builder.build`
- SDS-AC-4 (IR-APP-001 AC-5): WHEN a Kotlin object implements JsonCodec THE SYSTEM SHALL compile with no platform types because spi is @NullMarked and encode's value is @Nullable → `JsonCodec`
- SDS-AC-5 (IR-APP-002 AC-2): WHEN RestApp is reflected THE SYSTEM SHALL find the wave 3 methods plus the wave 4 set, with create and builder the only static methods; the IR-HTTP-005 AC-5 surface test is re-pointed → `RestApp.use`, `RestApp.get`, `RestApp.route`, `RestApp.create`
- SDS-AC-6 (IR-APP-002 AC-3): WHEN RouteBuilder.use is called between method registrations THE SYSTEM SHALL apply only the middleware added before each registration, in use order → `RouteBuilder.use`
- SDS-AC-7 (IR-APP-002 AC-4): WHEN a middleware, prefix or handler argument is null or the prefix lacks a leading / THE SYSTEM SHALL throw NullPointerException or IllegalArgumentException before recording anything → `RestApp.use`, `RestApp.get`
- SDS-AC-8 (IR-APP-002 AC-6): WHEN Kotlin calls app.use { req, res, next -> } and app.get("/x", mw) { req, res -> } THE SYSTEM SHALL resolve them by SAM conversion with no overload ambiguity → `Middleware`, `RestApp.get`
- SDS-AC-9 (IR-APP-003 AC-2): WHEN HttpException is constructed with a status outside 400..599 THE SYSTEM SHALL throw IllegalArgumentException naming the status → `HttpException.status`
- SDS-AC-10 (IR-APP-003 AC-3): WHEN code() is called THE SYSTEM SHALL return the FR-APP-006 code of the status, e.g. 400 BAD_REQUEST, 422 UNPROCESSABLE_ENTITY, 415 UNSUPPORTED_MEDIA_TYPE → `HttpException.code`, `UnsupportedMediaTypeException`
- SDS-AC-11 (IR-APP-003 AC-5): WHEN onError(null) is called THE SYSTEM SHALL throw NullPointerException; the NEW-state guard is the FR-APP-002 one → `RestApp.onError`, `ErrorHandler`
- SDS-AC-12 (FR-APP-001 AC-2): WHEN the loader exposes one provider THE SYSTEM SHALL return what its create() returned → `AppFactoryLoader.create`
- SDS-AC-13 (FR-APP-001 AC-3): WHEN no provider is found THE SYSTEM SHALL throw IllegalStateException with com.snoworca.naruserve:NaruServe and RestApp.builder() in the message → `AppFactoryLoader.create`, `RestApp.create`
- SDS-AC-14 (FR-APP-001 AC-4): WHEN two providers are found THE SYSTEM SHALL throw IllegalStateException listing every provider class name → `AppFactoryLoader.create`
- SDS-AC-15 (FR-APP-001 AC-5): WHEN the loader test runs THE SYSTEM SHALL write the services file into a temp dir seen only by a URLClassLoader whose parent holds the nested fake providers → `AppFactory`
