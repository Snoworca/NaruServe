## Acceptance Contracts

- SDS-AC-1 (IR-ROUTE-004 AC-1): WHEN a RouteMatch of a kind is read THE SYSTEM SHALL return null from handler, method, routeKind and allow where that kind carries no such field, and an empty params map → `RouteMatch.handler`, `RouteMatch.allow`, `RouteMatch.params`
- SDS-AC-2 (IR-ROUTE-004 AC-4): WHEN lookup receives a path PathValidator.isValid rejects THE SYSTEM SHALL throw IllegalArgumentException naming the path before reading the method token → `Router.lookup`
- SDS-AC-3 (IR-ROUTE-004 AC-5): WHEN lookup runs before freeze, or add runs after freeze THE SYSTEM SHALL throw IllegalStateException; WHEN upgrade is true and the token is not exactly GET THE SYSTEM SHALL treat upgrade as false → `Router.lookup`
- SDS-AC-4 (IR-ROUTE-004 AC-3): WHEN the path matches THE SYSTEM SHALL try in order the request method's most specific route, AUTO_OPTIONS for OPTIONS, automatic HEAD for HEAD, WEBSOCKET_ONLY, then METHOD_MISMATCH → `Router.lookup`
- SDS-AC-5 (FR-ROUTE-009 AC-2): WHEN no HTTP or WebSocket pattern matches the decoded segments THE SYSTEM SHALL return NO_MATCH for every routable method including OPTIONS → `Router.lookup`
- SDS-AC-6 (FR-ROUTE-010 AC-1): WHEN an Allow set is built THE SYSTEM SHALL return a MethodSet whose iteration and toString follow Method declaration order → `Router.allowFor`
- SDS-AC-7 (FR-ROUTE-011 AC-1): WHEN HEAD resolves to an HTTP GET route THE SYSTEM SHALL return MATCHED with method GET, routeKind HTTP and autoHead true → `RouteMatch.autoHead`
- SDS-AC-8 (FR-ROUTE-012 AC-1): WHEN OPTIONS has no matching OPTIONS route on a matched path THE SYSTEM SHALL return AUTO_OPTIONS with allow equal to allowFor of the path → `Router.allowFor`
- SDS-AC-9 (FR-ROUTE-013 AC-1): WHEN the token is compared THE SYSTEM SHALL require an exact case-sensitive equal to a Method name, without Method.valueOf exceptions → `Router.lookup`
- SDS-AC-10 (FR-ROUTE-014 AC-1): WHEN the token is TRACE or CONNECT and the policy leaves it disabled THE SYSTEM SHALL return UNSUPPORTED_METHOD before any path matching → `Router.lookup`
- SDS-AC-11 (FR-ROUTE-015 AC-2): WHEN isWebSocketUpgrade parses Connection and Upgrade THE SYSTEM SHALL split each on ',', trim, compare tokens with equalsIgnoreCase, and return false for null headers or a non-GET token → `Router.isWebSocketUpgrade`
- SDS-AC-12 (FR-ROUTE-016 AC-1): WHEN a request without upgrade has no route of its method THE SYSTEM SHALL return WEBSOCKET_ONLY if it is GET or HEAD and a WS but no HTTP GET route matches, or if every matching route is WS → `Router.lookup`
- SDS-AC-13 (FR-ROUTE-017 AC-1): WHEN upgrade is true and no WS pattern matches THE SYSTEM SHALL resolve as a GET without upgrade and return routeKind HTTP on a match → `Router.lookup`
