## Acceptance Contracts

- SDS-AC-1 (IR-JSON-001 AC-2): WHEN the captured type argument is a Class-less raw type or a TypeVariable THE SYSTEM SHALL throw IllegalStateException "TypeRef needs a concrete type argument" → `TypeRef.getType`
- SDS-AC-2 (IR-JSON-001 AC-3): WHEN the NaruServe-api jar is built THE SYSTEM SHALL contain META-INF/proguard/naruserve-api.pro with the three keep lines and a -keepclassmembers line for Cookie.unvalidated → `TypeRef`
- SDS-AC-3 (IR-JSON-002 AC-1): WHEN jsonCodec(c2) replaced the builder codec THE SYSTEM SHALL route req.body and res.json to c2 through DefaultRestApp.jsonCodec() read at freeze → `jsonCodec`
- SDS-AC-4 (IR-JSON-002 AC-2): WHEN jsonLimit gets 0, -1 or 1073741825 THE SYSTEM SHALL throw IllegalArgumentException naming jsonLimit and the range → `jsonLimit`
- SDS-AC-5 (IR-JSON-002 AC-4): WHEN reflection reads JsonCodec.decode THE SYSTEM SHALL find @Nullable on getAnnotatedReturnType and the erased return Object → `decode`
- SDS-AC-6 (IR-JSON-002 AC-8): WHEN the surface tests run THE SYSTEM SHALL expect body x2 and json added, the later-wave list without body/json and the nullable set plus three positions → `body`, `json`
- SDS-AC-7 (FR-JSON-001 AC-1): WHEN Content-Type is missing or not a JSON type THE SYSTEM SHALL throw UnsupportedMediaTypeException before the codec or the stream is touched → `isJsonType`
- SDS-AC-8 (FR-JSON-001 AC-2): WHEN the body is empty or whitespace only THE SYSTEM SHALL throw HttpException 400 without calling the codec, using a PushbackReader to peek → `read`
- SDS-AC-9 (FR-JSON-001 AC-4): WHEN Content-Length exceeds the limit THE SYSTEM SHALL throw HttpException 413 before reading; a chunked overrun wrapped by Gson SHALL also map to 413 → `overrun`
- SDS-AC-10 (FR-JSON-001 AC-6): WHEN the body bytes are invalid UTF-8 THE SYSTEM SHALL decode with a REPORT CharsetDecoder and map the MalformedInputException to 400 → `read`
- SDS-AC-11 (FR-JSON-001 AC-9): WHEN the decode failure's cause chain holds an HttpException THE SYSTEM SHALL rethrow that HttpException unchanged → `read`
- SDS-AC-12 (FR-JSON-002 AC-4): WHEN encode writes then throws THE SYSTEM SHALL discard the buffer, keep the response NEW and let the error path answer 500 → `json`
- SDS-AC-13 (FR-JSON-002 AC-5): WHEN json is called on a committed response THE SYSTEM SHALL throw IllegalStateException before encode → `json`
