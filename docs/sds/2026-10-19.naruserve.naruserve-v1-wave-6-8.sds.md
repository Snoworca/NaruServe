### Files

- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/DirectoryListing.java` — escaped, sorted HTML listing @req FR-STATIC-003
  - `static String render(String rawDirPath, File dir): String` — skips dot entries and symlinks; sorted by String.compareTo on raw names ← StaticHandler
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/CachePattern.java` — mount-relative cache pattern matching @req FR-STATIC-008
  - `static @Nullable CachePolicy select(List<Map.Entry<String, CachePolicy>> patterns, String relative)` — first registered match wins
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/FileResponder.java` — engine-free validators, conditionals and single ranges @req FR-STATIC-009, FR-STATIC-010, FR-STATIC-011
  - `final class FileResponder` — no adapter, TinyHttpd or Servlet reference
    - `static void respond(DefaultRequest req, DefaultResponse res, ResourceResolver r, String path, String type, @Nullable CachePolicy policy) throws IOException` ← StaticHandler, DefaultResponse
    - `static String etag(long length, long modified)` — "<hex length>-<hex millis>", strong
    - `static boolean noneMatch(@Nullable String ifNoneMatch, String etag)` — weak comparison, list and *
    - `static @Nullable long[] range(@Nullable String header, long length)` — one range or null; {-1} for 416
    - `static boolean ifRangeHolds(@Nullable String ifRange, String etag, long modifiedSeconds)`
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/DefaultResponse.java` — cache, file, download, file bodies and defaultCache at commit @req FR-STATIC-003, FR-STATIC-008, FR-STATIC-011
  - `cache(CachePolicy policy): Response` — replaces Cache-Control; last call before commit wins
  - `file(File file): void` / `download(File file, String filename): void` — FileResourceResolver.forFile, then FileResponder
  - `sendBody(int status, InputStream in, long skip, long length): void` — ex.commit(status, headers, length), 8192-byte copy, closes in; never ex.sendFile
  - `static String disposition(String filename): String` — attachment; ASCII fallback plus filename*=UTF-8''
  - `applyDefaultCache(@Nullable CachePolicy policy): void` — at commit, only when no Cache-Control is set

## Acceptance Contracts

- SDS-AC-1 (FR-STATIC-003 AC-2): WHEN an entry is a directory THE SYSTEM SHALL list it with a trailing '/' in text and href; links are relative names, HTML-escaped text and percent-encoded UTF-8 href → `render`
- SDS-AC-2 (FR-STATIC-003 AC-3): WHEN FileResponder or the listing answers 200, 206, 304 or 416 THE SYSTEM SHALL add X-Content-Type-Options: nosniff → `respond`
- SDS-AC-3 (FR-STATIC-008 AC-4): WHEN a pattern is compiled THE SYSTEM SHALL treat a pattern without leading '/' as "**/" + pattern, '*' as [^/]*, "**/" as zero or more segments and match the whole mount-relative path → `select`
- SDS-AC-4 (FR-STATIC-008 AC-5): WHEN defaultCache is set THE SYSTEM SHALL add it at commit to every response, error and 304 responses included, that holds no Cache-Control → `applyDefaultCache`
- SDS-AC-5 (FR-STATIC-009 AC-2): WHEN the method is neither GET nor HEAD THE SYSTEM SHALL ignore If-None-Match, If-Modified-Since, Range and If-Range and send the full 200 → `respond`
- SDS-AC-6 (FR-STATIC-009 AC-3): WHEN If-Modified-Since is compared THE SYSTEM SHALL compare whole seconds of the parsed IMF-fixdate (RFC 850 and asctime also accepted) with modified/1000 → `respond`
- SDS-AC-7 (FR-STATIC-010 AC-1): WHEN HEAD carries Range THE SYSTEM SHALL ignore it and answer the 200 headers; Range applies to GET only → `range`
- SDS-AC-8 (FR-STATIC-010 AC-2): WHEN the single range is unsatisfiable THE SYSTEM SHALL answer 416 through the standard error body with Content-Range: bytes */<length> and the same ETag and Last-Modified → `range`
- SDS-AC-9 (FR-STATIC-010 AC-4): WHEN If-Range is a date THE SYSTEM SHALL hold only when its seconds equal the Last-Modified seconds → `ifRangeHolds`
- SDS-AC-10 (FR-STATIC-011 AC-2): WHEN the download filename is sanitised THE SYSTEM SHALL drop CR, LF, '"', '\\' and other controls, replace non-ASCII by '_' in filename, and add filename* only when the name has non-ASCII → `disposition`
- SDS-AC-11 (FR-STATIC-011 AC-1): WHEN res.file or res.download runs THE SYSTEM SHALL take the type from the app MimeTypes and BUILT_IN only and evaluate conditionals and Range like a static file → `file`, `download`
- SDS-AC-12 (FR-STATIC-011 AC-4): WHEN a file body is sent THE SYSTEM SHALL skip with a loop over InputStream.skip then read, failing with IOException if fewer bytes exist → `sendBody`
