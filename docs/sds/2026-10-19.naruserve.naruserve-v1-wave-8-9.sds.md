## Acceptance Contracts

- SDS-AC-1 (FR-REL-001 AC-1): WHEN `./gradlew -Prelease releaseSbom` runs THE SYSTEM SHALL write nine files `<module>.cdx.json` (CycloneDX JSON, runtimeClasspath components only, none for compileOnly or test scope) under build/reports/naruserve/sbom, one per naruModules entry → `releaseSbom`
- SDS-AC-2 (FR-REL-001 AC-2): WHEN the release machine ran releaseSbom THE SYSTEM SHALL carry in the `sbom` run line of test-results.md the command, date, nine file names and per-file component counts → `RUN_NAMES`
- SDS-AC-3 (FR-REL-001 AC-3): WHEN the build files are scanned as text THE SYSTEM SHALL find the guarded apply in build.gradle, the strings `cyclonedx` and `dependencycheck` (any case) only in gradle/release.gradle, every plugin version there an exact `\d+\.\d+\.\d+` literal, and no release task in a dependsOn or finalizedBy of check, build or test → `releaseApply`, `ReleaseScriptTextTest`
- SDS-AC-4 (FR-REL-001 AC-4): WHEN the release machine ran `./gradlew build --offline` with a Gradle user home lacking both release plugins THE SYSTEM SHALL carry in the `offline-build` run line its command, date and `exit=0` → `RUN_NAMES`
- SDS-AC-5 (FR-REL-001 AC-5): WHEN the default build runs THE SYSTEM SHALL pass the two re-pointed BuildLayoutTest methods with unchanged expectations plus the conditional-apply check → `con_BUILD_017_AC1_rootBuildFileHoldsPluginsCompileDependenciesAndChecks`, `con_BUILD_017_AC2_noModuleBuildFile`, `con_BUILD_017_AC1_onlyReferenceToAnotherScriptIsTheGuardedReleaseApply`
- SDS-AC-6 (CON-BUILD-017 AC-1): WHEN build.gradle is read THE SYSTEM SHALL hold the plugin, compile, dependency and check configuration of every module and one `apply from:` only, the guarded release apply → `releaseApply`, `con_BUILD_017_AC1_onlyReferenceToAnotherScriptIsTheGuardedReleaseApply`
- SDS-AC-7 (CON-BUILD-017 AC-2): WHEN module directories are listed THE SYSTEM SHALL find no build.gradle, build.gradle.kts or pom.xml in any of the nine modules; gradle/release.gradle sits outside module directories → `con_BUILD_017_AC2_noModuleBuildFile`
- SDS-AC-8 (CON-BUILD-017 AC-3): WHEN CLAUDE.md is read THE SYSTEM SHALL state the release-only script exception in one sentence while ops_BUILD_003_AC3_AC4 still passes → `releaseExceptionSentence`, `con_BUILD_017_AC3_claudeMdStatesReleaseScriptException`
