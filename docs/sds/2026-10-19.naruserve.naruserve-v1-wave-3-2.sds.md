## Acceptance Contracts

- SDS-AC-1 (IR-HTTP-003 AC-1): WHEN the adapter exposes headers THE SYSTEM SHALL return them as a List of Map.Entry in received order with duplicates kept, not a Map → `HttpExchange.headers`
- SDS-AC-2 (IR-HTTP-003 AC-2): WHEN the core commits THE SYSTEM SHALL pass status, headers and the content length in one commit call that returns the body OutputStream, and a second commit SHALL throw IllegalStateException → `HttpExchange.commit`
- SDS-AC-3 (IR-HTTP-003 AC-3): WHEN target /a%20b?x=%41 arrives THE SYSTEM SHALL deliver rawPath /a%20b and rawQuery x=%41 undecoded, and rawQuery null when the target has no '?' → `HttpExchange.rawQuery`, `InMemoryHttpAdapter.splitTarget`
- SDS-AC-4 (IR-HTTP-004 AC-3): WHEN eventStream is called THE SYSTEM SHALL return to the caller at once and the in-memory adapter SHALL run the drain on its own worker thread, completing the client response when drain returns → `HttpExchange.eventStream`, `StreamDrain.drain`
- SDS-AC-5 (IR-HTTP-004 AC-5): WHEN bind gets port 0 THE SYSTEM SHALL assign a positive in-memory port from a counter starting at 49152, and a positive port SHALL be reported as given → `HttpAdapter.bind`, `HttpAdapter.boundPort`
- SDS-AC-6 (IR-HTTP-004 AC-6): WHEN stop reaches its deadline with an exchange in flight THE SYSTEM SHALL abort that exchange so its ClientResponse reports abnormallyClosed, and release SHALL shut the worker pool waiting at most 1 second → `HttpAdapter.stop`, `HttpAdapter.release`
- SDS-AC-7 (CON-HTTP-001 AC-1): WHEN SPI signatures are reflected THE SYSTEM SHALL reference only java.*, com.snoworca.naruserve and org.jspecify types, excluding java.nio.file, CompletableFuture and java.net.http → `HttpAdapter`, `HttpExchange`
- SDS-AC-8 (FR-HTTP-001 AC-3): WHEN start runs the freeze and it throws RoutingConfigException THE SYSTEM SHALL rethrow that exception itself, unwrapped, to the test caller → `TestApp.start`
- SDS-AC-9 (FR-HTTP-001 AC-5): WHEN method is CONNECT and the target does not start with '/' THE SYSTEM SHALL answer 501 with Content-Length 0 without calling the ExchangeHandler → `InMemoryHttpAdapter.send`
- SDS-AC-10 (FR-HTTP-001 AC-6): WHEN the target is absolute-form scheme://authority/path?query THE SYSTEM SHALL keep only path (or / when empty) and query; '*' SHALL pass as raw path * → `InMemoryHttpAdapter.splitTarget`
- SDS-AC-11 (OPS-HTTP-002 AC-1): WHEN the root test classpath gains NaruServe-api THE SYSTEM SHALL keep JUnit 4, gradleTestKit, the test task dependencies and the system properties unchanged → `rootTestClasspath`
