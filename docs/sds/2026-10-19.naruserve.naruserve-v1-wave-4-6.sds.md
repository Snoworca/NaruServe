## Acceptance Contracts

- SDS-AC-1 (FR-APP-007 AC-1): WHEN a handler calls req.service(T) THE SYSTEM SHALL return the same object as req.application().get(T), with no separate lookup path → `service`, `application`
- SDS-AC-2 (FR-APP-007 AC-2): WHEN register, registerExternal or own runs while the state is not STARTING or after freeze THE SYSTEM SHALL throw IllegalStateException naming the method and the state before touching the registry or the close list → `DefaultApplicationContext.register`, `DefaultApplicationContext.registerExternal`, `DefaultApplicationContext.own`
- SDS-AC-3 (FR-APP-007 AC-3): WHEN a key is registered a second time by register or registerExternal THE SYSTEM SHALL throw IllegalStateException whose message contains the key's class name, keep the first instance and not track the second → `DefaultApplicationContext.register`
- SDS-AC-4 (FR-APP-007 AC-3): WHEN a close hook of a failing start calls getOrNull THE SYSTEM SHALL read the unfrozen live map and return the first instance → `DefaultApplicationContext.getOrNull`
- SDS-AC-5 (FR-APP-007 AC-4): WHEN the state becomes RUNNING THE SYSTEM SHALL already have published the unmodifiable snapshot, so lock-free concurrent reads see every registered service → `DefaultApplicationContext.freeze`, `DefaultApplicationContext.get`
- SDS-AC-6 (FR-APP-007 AC-5): WHEN listen succeeds THE SYSTEM SHALL run each onStart callback once in registration order and shutdown SHALL run none of them → `listen`
- SDS-AC-7 (FR-APP-007 AC-6): WHEN attribute is written or read in onStart, RUNNING or onStop THE SYSTEM SHALL use the ConcurrentHashMap without the lifecycle gate → `DefaultApplicationContext.attribute`
- SDS-AC-8 (FR-APP-007 AC-7): WHEN ctx.logger() is called THE SYSTEM SHALL return app.logger() read at call time, the raw logger and not the SafeLogger wrapper → `DefaultApplicationContext.logger`
- SDS-AC-9 (FR-APP-007 AC-8): WHEN onStart, onStop or a request receives a context THE SYSTEM SHALL pass the one instance created in the DefaultRestApp constructor → `context`
- SDS-AC-10 (FR-APP-008 AC-1): WHEN shutdown or start failure closes resources THE SYSTEM SHALL close in reverse order of the first own or register call of each object → `OwnedResources.closeAll`
- SDS-AC-11 (FR-APP-008 AC-2): WHEN one object is tracked by own and by register under two keys THE SYSTEM SHALL keep only its first position and close it once → `OwnedResources.add`
- SDS-AC-12 (FR-APP-008 AC-3): WHEN a close throws THE SYSTEM SHALL continue with the rest; shutdown logs each failure at ERROR and a failing listen adds each as suppressed to the exception it throws → `OwnedResources.closeAll`, `shutdown`, `listen`
- SDS-AC-13 (FR-APP-008 AC-4): WHEN an object is registered only through registerExternal THE SYSTEM SHALL never track it, and an own of the same object tracks it once → `DefaultApplicationContext.registerExternal`
- SDS-AC-14 (FR-APP-008 AC-5): WHEN the registered instance is not AutoCloseable THE SYSTEM SHALL register it without tracking → `DefaultApplicationContext.register`
