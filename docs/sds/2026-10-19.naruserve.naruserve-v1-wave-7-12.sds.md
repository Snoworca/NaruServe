## Acceptance Contracts

- SDS-AC-1 (FR-APP-019 AC-8): WHEN onOpen runs THE SYSTEM SHALL write the handshake line after the channel is stored and before the handler, with the duration from req.startNanos() → `DefaultWebSocketSession.onOpen`, `startNanos`
- SDS-AC-2 (FR-APP-019 AC-8): WHEN the response ends with upgraded101() true THE SYSTEM SHALL write no line from onDone; a refusal before onOpen never calls upgraded, so its ordinary line is written → `Dispatcher.handle`, `upgraded101`
- SDS-AC-3 (FR-APP-019 AC-9): WHEN the endpoint onClose first runs THE SYSTEM SHALL call writeClose once with the code it reports to the CloseListeners and the time since openNanos → `DefaultWebSocketSession.onClose`, `writeClose`
- SDS-AC-4 (FR-APP-019 AC-10): WHEN a response with sseClient() non-null ends THE SYSTEM SHALL call writeSse with status 200, out = bytesWritten(), startMillis and cause() of the client; a null cause cannot occur because sseEnded runs only after endBy → `writeSse`, `Dispatcher.handle`
- SDS-AC-5 (FR-APP-019 AC-11): WHEN a path is excluded or the log disabled THE SYSTEM SHALL drop the close and SSE lines by the same check as write, and use the configured level → `writeClose`, `writeSse`
- SDS-AC-6 (FR-APP-020 AC-1): WHEN participants of both kinds are added to one phase THE SYSTEM SHALL keep one list in add order, wrapping a Runnable as d -> r.run() → `add`, `DeadlineParticipant`
- SDS-AC-7 (FR-APP-020 AC-1): WHEN shutdown runs the sequence THE SYSTEM SHALL pass the deadline computed at shutdown entry to every phase run → `runShutdownSequence`, `run`
- SDS-AC-8 (FR-APP-020 AC-3): WHEN register returns false THE SYSTEM SHALL still start the event stream, with the notice queued and the client ended, so the client gets headers, notice and end of body and onClose runs once → `DefaultResponse.sse`
- SDS-AC-9 (FR-APP-020 AC-9): WHEN the thread check runs THE SYSTEM SHALL run it in the isolatedTest task, one JVM per class, counting threads named naruserve-*, tinyhttpd-acceptor-<port> and tinyhttpd-watchdog → `isolatedTest`
