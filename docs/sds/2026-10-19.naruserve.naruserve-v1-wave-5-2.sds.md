## Acceptance Contracts

- SDS-AC-1 (FR-JSON-003 AC-1): WHEN gson is null or maxDepth is 0 or 256 THE SYSTEM SHALL throw NullPointerException or IllegalArgumentException naming maxDepth before any state is kept → `GsonJsonCodec.GsonJsonCodec`
- SDS-AC-2 (FR-JSON-003 AC-2): WHEN the default codec reads unquoted names, single quotes or comments THE SYSTEM SHALL throw IOException whose cause is the Gson syntax exception → `GsonJsonCodec.decode`
- SDS-AC-3 (FR-JSON-003 AC-3): WHEN the target class has no no-arg constructor THE SYSTEM SHALL let Gson's JsonIOException propagate unchecked and create no instance → `GsonJsonCodec.decode`
- SDS-AC-4 (FR-JSON-003 AC-4): WHEN any instance, including one built from a caller Gson, decodes nesting maxDepth+1 THE SYSTEM SHALL throw IOException, because the limit is set on the reader on every decode → `GsonJsonCodec.decode`
- SDS-AC-5 (FR-JSON-003 AC-5): WHEN tokens remain after the first value THE SYSTEM SHALL throw IOException; a null document SHALL return null → `GsonJsonCodec.decode`
- SDS-AC-6 (FR-JSON-003 AC-6): WHEN Gson throws JsonSyntaxException or MalformedJsonException THE SYSTEM SHALL rethrow java.io.IOException with that cause; JsonIOException SHALL stay unchecked → `GsonJsonCodec.decode`
- SDS-AC-7 (FR-JSON-003 AC-7): WHEN encode gets null, a String or a List THE SYSTEM SHALL write null, a quoted string and an array → `GsonJsonCodec.encode`
- SDS-AC-8 (FR-JSON-003 AC-8): WHEN the module is built THE SYSTEM SHALL pass animal-sniffer API 21 and a Kotlin test SHALL pass GsonJsonCodec(defaultGson(), 32) to app.jsonCodec → `GsonJsonCodec.defaultGson`
