  - `final class TinyHttpdBodyStream extends FilterInputStream` — read/skip translate TinyHttpd exceptions

- `NaruServe-tinyhttpd/src/main/java/com/snoworca/naruserve/tinyhttpd/JsonErrorHandler.java` — TinyHttpd ErrorHandler writing the standard error body @req FR-ENGINE-005
  - `final class JsonErrorHandler implements ErrorHandler` — render(status, message, req, res): status, JSON type, settings.errorRenderer().render(status)
- `NaruServe-tinyhttpd/src/main/java/com/snoworca/naruserve/tinyhttpd/TinyLogBridge.java` — TinyLog to app Logger @req FR-ENGINE-005
  - `final class TinyLogBridge implements TinyLog` — isLoggable always true; SEVERE→error, WARNING→warn, INFO→info, CONFIG/FINE→debug, FINER/FINEST→trace
- `NaruServe-tinyhttpd/src/main/java/com/snoworca/naruserve/tinyhttpd/KeeperThread.java` — non-daemon JVM keeper @req FR-ENGINE-006
  - `final class KeeperThread` — start(port) after a successful start(); end() at stop begin
- `NaruServe-tinyhttpd/src/main/java/com/snoworca/naruserve/tinyhttpd/WorkerThreadFactory.java` — worker naming and defaults @req FR-ENGINE-006
  - `final class WorkerThreadFactory implements ThreadFactory` — naruserve-<port>-worker-<n>, daemon, 256 KiB stack, uncaught → logger.error
- `NaruServe-tinyhttpd/src/main/java/com/snoworca/naruserve/tinyhttpd/TinyHttpdAdapter.java` — stop and release @req FR-ENGINE-005, FR-ENGINE-006
  - `stop(long timeout, TimeUnit unit): void` — keeper.end(); server.stop(max(0, millis)) once
  - `release(): void` — awaitTermination(1000); warns when workers remain

## Acceptance Contracts

- SDS-AC-1 (FR-ENGINE-005 AC-1): WHEN the body stream throws SocketTimeoutException, TruncatedBodyException or a constructed BodyTooLargeException THE SYSTEM SHALL throw HttpException 408, 400 or 413 with the original as cause → `TinyHttpdBodyStream.map`
- SDS-AC-2 (FR-ENGINE-005 AC-1): WHEN a handler writes past its declared Content-Length THE SYSTEM SHALL leave ContentLengthExceededException unmapped → `TinyHttpdBodyStream.map`
- SDS-AC-3 (FR-ENGINE-005 AC-3): WHEN TinyHttpd raises 421 for a Host outside the allowlist THE SYSTEM SHALL write the renderer body with application/json; charset=UTF-8 → `JsonErrorHandler`
- SDS-AC-4 (FR-ENGINE-005 AC-4): WHEN a request line, header section or version is rejected before dispatch THE SYSTEM SHALL leave TinyHttpd's plain answer and record nothing in onError or the access log → `JsonErrorHandler`
- SDS-AC-5 (FR-ENGINE-005 AC-5): WHEN CONNECT / and CONNECT example.com:443 arrive THE SYSTEM SHALL produce the dispatcher 501 with an access line and the transport 501 without one → `JsonErrorHandler`
- SDS-AC-6 (FR-ENGINE-005 AC-6): WHEN TinyHttpd logs a WARNING with a throwable THE SYSTEM SHALL call warn(message + ": " + throwable) since Logger has no warn(String, Throwable) → `TinyLogBridge`
- SDS-AC-7 (FR-ENGINE-006 AC-1): WHEN shutdown(t, unit) runs THE SYSTEM SHALL pass the full time left as grace and return within deadline + 1500 ms → `stop`
- SDS-AC-8 (FR-ENGINE-006 AC-2): WHEN shutdown returned THE SYSTEM SHALL leave no naruserve-<port>- worker, no tinyhttpd-acceptor-<port>, no keeper and no watchdog thread → `release`
- SDS-AC-9 (FR-ENGINE-006 AC-3): WHEN a keep-alive request races the stop THE SYSTEM SHALL answer 503 with Connection: close or close without a response → `stop`
- SDS-AC-10 (FR-ENGINE-006 AC-4): WHEN bind succeeded THE SYSTEM SHALL run exactly one non-daemon naruserve-keeper-<port> thread while TinyHttpd threads stay daemon → `KeeperThread`
- SDS-AC-11 (FR-ENGINE-006 AC-5): WHEN a child JVM main returns after listen(0) THE SYSTEM SHALL keep serving until the shutdown route is requested → `KeeperThread`
- SDS-AC-12 (FR-ENGINE-006 AC-2): WHEN TinyHttpd creates a worker THE SYSTEM SHALL name it with the bound port read at creation time, daemon, 256 KiB stack → `WorkerThreadFactory`
