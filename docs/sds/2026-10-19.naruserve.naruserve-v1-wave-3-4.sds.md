## Acceptance Contracts

- SDS-AC-1 (FR-HTTP-009 AC-1): WHEN path() is computed THE SYSTEM SHALL percent-decode the raw path once as UTF-8 keeping '+', without applying mergeSlashes, trailing-slash or case policy → `DefaultRequest.decodePath`
- SDS-AC-2 (FR-HTTP-009 AC-4): WHEN param names a variable absent from the matched pattern THE SYSTEM SHALL throw IllegalArgumentException whose message contains the name → `DefaultRequest.param`
- SDS-AC-3 (FR-HTTP-010 AC-2): WHEN a query pair has no '=' THE SYSTEM SHALL read its value as the empty string, keep empty names, and decode names and values with '+' as space → `DefaultRequest.parseQuery`
- SDS-AC-4 (FR-HTTP-010 AC-3): WHEN a %XX is malformed or the bytes are not valid UTF-8 (CodingErrorAction.REPORT) THE SYSTEM SHALL throw IllegalArgumentException, which the Dispatcher turns into 400 with Content-Length 0 before the handler runs → `DefaultRequest.decodeQuery`, `DefaultRequest.parseQuery`
- SDS-AC-5 (FR-HTTP-011 AC-1): WHEN headers(name) finds no match THE SYSTEM SHALL return an empty unmodifiable list, and header(name) null → `DefaultRequest.header`, `DefaultRequest.headers`
- SDS-AC-6 (FR-HTTP-011 AC-3): WHEN Last-Event-ID appears more than once THE SYSTEM SHALL return the first value → `DefaultRequest.lastEventId`
- SDS-AC-7 (FR-HTTP-012 AC-4): WHEN attribute(key, value) gets null THE SYSTEM SHALL remove the key, so the map never holds null → `DefaultRequest.attribute`
- SDS-AC-8 (FR-HTTP-012 AC-5): WHEN the stored value is not an instance of type THE SYSTEM SHALL throw ClassCastException from type.cast → `DefaultRequest.attribute`
- SDS-AC-9 (FR-HTTP-019 AC-3): WHEN begin is called in any state other than UNREAD THE SYSTEM SHALL throw BodyAlreadyConsumedException naming the current state → `BodyState.begin`
- SDS-AC-10 (FR-HTTP-019 AC-4): WHEN sharedParse runs after begin, or begin runs after sharedParse, THE SYSTEM SHALL throw BodyAlreadyConsumedException; a parser failure leaves CONSUMED with no cache and later calls throw BodyAlreadyConsumedException → `BodyState.sharedParse`
- SDS-AC-11 (FR-HTTP-019 AC-2): WHEN close is called THE SYSTEM SHALL move to CLOSED from any state and later begin or sharedParse SHALL throw → `BodyState.close`, `BodyState.state`
- SDS-AC-12 (FR-HTTP-020 AC-3): WHEN a read would return byte limit+1 THE SYSTEM SHALL read at most limit+1 bytes from the source and throw BodyTooLargeException, returning no byte past the limit → `LimitedInputStream.read`, `BodyTooLargeException`
- SDS-AC-13 (FR-HTTP-020 AC-4): WHEN declaredLength exceeds limit THE SYSTEM SHALL throw BodyTooLargeException on the first read without touching the source → `LimitedInputStream.read`
