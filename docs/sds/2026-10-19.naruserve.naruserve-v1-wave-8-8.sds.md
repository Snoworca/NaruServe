## Acceptance Contracts

- SDS-AC-1 (FR-SVL-006 AC-1): WHEN a slow request is in flight and stop(2, SECONDS) runs THE SYSTEM SHALL answer new requests 503 with Connection: close and the standard body at once, return when the slow request finishes, and return no later than the deadline plus 1 s otherwise → `ServletAdapter.stop`, `ServletAdapter.enter`
- SDS-AC-2 (FR-SVL-006 AC-2): WHEN streams are open at shutdown THE SYSTEM SHALL let the core deliver the closing notice, end each client's chunked body within the timeout plus the D-344 margin, complete each AsyncContext and shut the executor down → `ServletAdapter.stop`, `Pool.completeAll`
- SDS-AC-3 (FR-SVL-006 AC-3): WHEN a stream's client stopped reading THE SYSTEM SHALL cut it at the deadline by AsyncContext.complete(), return from stop within the deadline plus 1 s, and servlet.md SHALL carry the deviation sentence with a pointer in sse.md → `Pool.completeAll`, `ServletDocsTest.cutAtTimeoutDeviation`
- SDS-AC-4 (FR-SVL-006 AC-4): WHEN release runs THE SYSTEM SHALL detach the handler so later requests get 503, keep stop and release idempotent, and leave no naruserve-servlet-sse-* thread within 2 s of shutdown → `ServletAdapter.release`
- SDS-AC-5 (FR-SVL-006 AC-5): WHEN any module test that starts the container ends THE SYSTEM SHALL assert, through the shared rule, no server thread and no upload temporary file of that app → `ContainerRule.after`
- SDS-AC-6 (OPS-SVL-001 AC-1): WHEN servlet.md is read THE SYSTEM SHALL hold no (미확정) marker and a jakarta sentence stating that no jakarta.servlet module exists in v1, with the OPS-BUILD-003 AC-5 assertion unchanged → `ServletDocsTest.noMarkerAndJakartaSentence`
- SDS-AC-7 (OPS-SVL-001 AC-2): WHEN servlet.md is read THE SYSTEM SHALL name ServletConfigurer, NaruServeInitializer, the three init-parameters with defaults, services-file discovery and asyncSupported=true, and show a web.xml example, Java and Kotlin configurers and the Express counterpart sentence → `ServletDocsTest.registrationSection`
- SDS-AC-8 (OPS-SVL-001 AC-3): WHEN servlet.md is read THE SYSTEM SHALL state port ownership with ServerHandle.port() 0, destroy-callback shutdown, path rules, multipart by the core parser, WebSocket 501, SSE under AsyncContext, the cut deviation, container header order, the OPTIONS * status, the Gson lookup, Jetty 9.4 only and the thread-total exception → `ServletDocsTest.sectionKeywords`
- SDS-AC-9 (OPS-SVL-001 AC-4): WHEN the root docs compile test runs THE SYSTEM SHALL compile the servlet.md Java blocks against project(':NaruServe-servlet') and accept SKIPS entries only for blocks that exist, and the FR-SVL-008 AC-4 lists SHALL stay present → `rootServletTestDependency`, `SKIPS`
- SDS-AC-10 (OPS-SVL-001 AC-5): WHEN docs/api/sse.md is compared with its wave 7 text THE SYSTEM SHALL differ only by the pointer sentence, and the Kotlin block of servlet.md SHALL be a fenced kotlin block the FR-KT-004 examples test reads → `ServletDocsTest.sseDocOnlyGainsPointer`
