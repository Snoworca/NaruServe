## Acceptance Contracts

- SDS-AC-1 (CON-ROUTE-001 AC-2): WHEN a test builds Router<String> and registers and looks up routes THE SYSTEM SHALL compile and pass with no Request, Response, RouteHandler or RestApp type in NaruServe-api main → `Router`
- SDS-AC-2 (CON-ROUTE-001 AC-3): WHEN the routing package is compiled THE SYSTEM SHALL carry @NullMarked in package-info and mark nullable returns with @Nullable → `RoutePattern.match`
- SDS-AC-3 (CON-ROUTE-001 AC-4): WHEN a lookup path carries "?query" THE SYSTEM SHALL drop the text from the first '?' before decoding and SHALL NOT parse authority or absolute-form targets → `Router.decodeSegments`
- SDS-AC-4 (FR-ROUTE-002 AC-3): WHEN addWebSocket registers a pattern THE SYSTEM SHALL store kind WEBSOCKET with method GET for Allow and conflict purposes → `Router.addWebSocket`
- SDS-AC-5 (FR-ROUTE-003 AC-3): WHEN add receives an invalid pattern THE SYSTEM SHALL throw RoutingConfigException from add, before freeze, naming the pattern → `RoutePattern.parse`
- SDS-AC-6 (FR-ROUTE-004 AC-1): WHEN a %XX sequence is malformed, encodes '/', NUL or an invalid UTF-8 byte sequence, or a segment equals '.' or '..' after decoding THE SYSTEM SHALL return false → `PathValidator.isValid`
- SDS-AC-7 (FR-ROUTE-004 AC-2): WHEN the raw path contains a char <= 0x20, 0x7F, '#' or a char > 0x7F THE SYSTEM SHALL return false → `PathValidator.isValid`
- SDS-AC-8 (FR-ROUTE-005 AC-3): WHEN a segment is decoded THE SYSTEM SHALL decode %XX exactly once as UTF-8 and keep '+' as '+' → `Router.decodeSegments`
- SDS-AC-9 (FR-ROUTE-006 AC-3): WHEN case-insensitive matching compares literals THE SYSTEM SHALL use locale-independent comparison (String.equalsIgnoreCase or toLowerCase(Locale.ROOT)) → `RoutePattern.match`
- SDS-AC-10 (FR-ROUTE-006 AC-4): WHEN a Router is constructed THE SYSTEM SHALL copy the immutable RouterPolicy and offer no setter after construction → `RouterPolicy.builder`, `Router`
- SDS-AC-11 (FR-ROUTE-007 AC-2): WHEN two patterns of one method match a path THE SYSTEM SHALL pick the one compareSpecificity ranks higher, independent of registration order → `RoutePattern.compareSpecificity`
- SDS-AC-12 (FR-ROUTE-008 AC-3): WHEN freeze finds conflicts THE SYSTEM SHALL throw one RoutingConfigException whose message has one line per conflicting pair "METHOD pattern conflicts with METHOD pattern" → `Router.freeze`
- SDS-AC-13 (FR-ROUTE-008 AC-4): WHEN conflict keys are computed THE SYSTEM SHALL compare registrations of the same kind and method by conflictKey under the router's policy → `RoutePattern.conflictKey`
- SDS-AC-14 (FR-ROUTE-008 AC-5): WHEN a TRACE or CONNECT registration exists while that method is disabled THE SYSTEM SHALL report it in the freeze error as "METHOD pattern registered while METHOD routing is disabled" → `Router.freeze`

## Durable Rules

- The router package com.snoworca.naruserve.routing stays engine-free (no adapter, Gson, Servlet, android or kotlin types) — adapters and Android builds share it.
- Router types avoid java.util.Optional, java.util.function and streams — the animal-sniffer API 21 check rejects them.
