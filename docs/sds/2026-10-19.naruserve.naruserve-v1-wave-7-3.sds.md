## Acceptance Contracts

- SDS-AC-1 (FR-WS-001 AC-1): WHEN an upgrade request matches an app.ws route THE SYSTEM SHALL make the terminal step only record that it was reached, and call WebSocketUpgrade.run after pipeline.run returned, only when it was reached and the response is still NEW → `Dispatcher.handle`, `run`
- SDS-AC-2 (FR-WS-001 AC-3): WHEN ex.webSocket opens the connection THE SYSTEM SHALL run the handler from onOpen on the adapter's calling thread after the channel is stored; a refusal before onOpen never runs it → `onOpen`
- SDS-AC-3 (FR-WS-001 AC-7): WHEN the matched route's handler is not a WebSocketRoute (the TestApp hook) THE SYSTEM SHALL complete the upgrade with a null handler and never call that RouteHandler → `run`
- SDS-AC-4 (FR-WS-001 AC-8): WHEN ex.webSocket returns THE SYSTEM SHALL call res.upgraded(), which finishes the exchange exactly once and writes no HTTP response, and Dispatcher.finish SHALL leave the COMPLETED response alone → `upgraded`, `Dispatcher.handle`
- SDS-AC-5 (FR-WS-001 AC-8): WHEN ex.webSocket throws and opened() is false THE SYSTEM SHALL rethrow to the error path; WHEN opened() is true THE SYSTEM SHALL log ERROR "websocket <rid> failed" and still call res.upgraded() → `run`, `opened`
- SDS-AC-6 (FR-WS-003 AC-2): WHEN admits is false THE SYSTEM SHALL throw HttpException(403) from run before any session exists, so the error path writes the standard body with the request id → `run`
- SDS-AC-7 (FR-WS-003 AC-3): WHEN Origin is checked THE SYSTEM SHALL lowercase scheme and host, take port 80 or 443 by scheme when absent, read Host as host[:port] with bracketed IPv6, and treat an unparseable Origin, or a present Origin with no Host, as not same-origin → `admits`
- SDS-AC-8 (FR-WS-003 AC-4): WHEN Origin is the literal null THE SYSTEM SHALL admit it only when `*` is listed → `admits`
- SDS-AC-9 (FR-WS-003 AC-5): WHEN an allowlist entry is configured THE SYSTEM SHALL normalise it as SDS-AC-7 once at freeze and compare normalised tuples, with `*` anywhere in the list admitting every Origin → `OriginCheck`
- SDS-AC-10 (FR-WS-003 AC-7): WHEN a middleware answered or never called next THE SYSTEM SHALL skip the Origin check and the upgrade, because both run only from the post-chain step of SDS-AC-1 → `run`
- SDS-AC-11 (FR-WS-004 AC-1): WHEN a non-upgrade request hits a path with only an app.ws route THE SYSTEM SHALL answer from the WEBSOCKET_ONLY fallback case with both headers and the standard body → `Dispatcher.fallback`
- SDS-AC-12 (FR-WS-004 AC-3): WHEN the docs test runs THE SYSTEM SHALL find TINYHTTPD_426_PHRASE verbatim in docs/api/websocket.md → `TINYHTTPD_426_PHRASE`
