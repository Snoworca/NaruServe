## Interfaces

### Depends

- DefaultRequest → MultipartParser → LimitedInputStream, SpoolRegistry, DefaultUploadFile
- DefaultRequest → FormBodyReader → LimitedInputStream, PercentDecoder

### Files

- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/MultipartParser.java` — streaming multipart/form-data parser shared by every adapter @req FR-MULTIPART-001, FR-MULTIPART-002
  - `final class MultipartParser` — no adapter, TinyHttpd, Servlet or java.nio.file reference; 8192-byte read buffer
    - `static @Nullable String boundary(@Nullable String contentType)` — null for missing, empty, over 70 chars or non-bchars ← DefaultRequest
    - `static List<DefaultUploadFile> parse(InputStream body, String boundary, MultipartSettings s, long formLimit, SpoolRegistry spool) throws IOException` — HttpException 400 or 413 ← DefaultRequest
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/FormBodyReader.java` — urlencoded body read under formLimit @req FR-MULTIPART-002
  - `static Map<String, List<String>> read(InputStream body, long contentLength, long formLimit) throws IOException` — LimitedInputStream then PercentDecoder.decode(s, true) ← DefaultRequest

## Acceptance Contracts

- SDS-AC-1 (FR-MULTIPART-001 AC-2): WHEN the boundary parameter is read THE SYSTEM SHALL match the parameter name case-insensitively, unquote a quoted-string value and accept only RFC 2046 bchars with no trailing space → `boundary`
- SDS-AC-2 (FR-MULTIPART-001 AC-2): WHEN a part has no Content-Disposition form-data with a name parameter, or the body ends before the close delimiter THE SYSTEM SHALL throw HttpException(400) after deleting every temp file of that parse → `parse`
- SDS-AC-3 (FR-MULTIPART-001 AC-2): WHEN bytes precede the first delimiter or follow the close delimiter THE SYSTEM SHALL ignore them as preamble and epilogue → `parse`
- SDS-AC-4 (FR-MULTIPART-001 AC-4): WHEN part header sizes are counted THE SYSTEM SHALL count line bytes without the CRLF for the 8192 line limit and the sum of those line lengths for the 16384 total → `parse`
- SDS-AC-5 (FR-MULTIPART-002 AC-1): WHEN the 21st part delimiter is reached under maxParts 20 THE SYSTEM SHALL throw HttpException(413) before that part's headers are read → `parse`
- SDS-AC-6 (FR-MULTIPART-002 AC-1): WHEN a file part's content passes maxFileSize THE SYSTEM SHALL throw HttpException(413) on the first byte above it; text parts never count against maxFileSize → `parse`
- SDS-AC-7 (FR-MULTIPART-002 AC-2): WHEN the body is counted THE SYSTEM SHALL wrap the BodyState stream in LimitedInputStream(maxRequestSize, Content-Length) so a Content-Length above the limit fails on the first read and a chunked body after limit plus one buffer → `parse`
- SDS-AC-8 (FR-MULTIPART-002 AC-3): WHEN the urlencoded body passes formLimit THE SYSTEM SHALL map BodyTooLargeException to HttpException(413) with or without Content-Length → `read`
