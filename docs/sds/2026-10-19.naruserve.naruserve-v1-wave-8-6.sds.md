### Files

- `NaruServe-servlet/src/main/java/com/snoworca/naruserve/servlet/ServletAdapter.java` — bind contract of the container-hosted adapter @req FR-SVL-001, FR-SVL-008
  - `public final class ServletAdapter implements HttpAdapter` — declares both bind overloads
    - `bind(String host, int port, ExchangeHandler handler): void` — stores the handler only; host and port ignored; no thread, no socket
    - `bind(ServerSettings settings, ExchangeHandler handler): void` — own override; keeps handler, maxSseStreams, errorRenderer and logger; reads no other option; no container-side body limit; a second bind is an IllegalStateException
    - `boundPort(): int` — IllegalStateException before any bind, 0 after
    - `settings(): @Nullable ServerSettings` — package-private, null before the settings bind ← NaruServeServlet
- `NaruServe-servlet/src/main/java/com/snoworca/naruserve/servlet/AppStarter.java` — start path shared by the initializer and tests @req FR-SVL-001
  - `final class AppStarter` — extends part 5
    - `create(ServletContext ctx, String className): RestApp` — calls presetCodec before configure; an IllegalStateException of configure becomes a ServletException that, without a found codec, also names com.snoworca.naruserve.gson.GsonJsonCodec and jsonCodec
    - `presetCodec(ServletContext ctx, RestApp.Builder b): boolean` — Class.forName of GsonJsonCodec with ctx.getClassLoader(), public no-argument constructor, Builder.jsonCodec; false when absent, so the configurer may still set one
    - `start(RestApp app): void` — app.listen(0); a RuntimeException, AppStartException included, becomes a ServletException with it as cause
- `NaruServe-servlet/src/main/java/com/snoworca/naruserve/servlet/ShutdownListener.java` — destroy callback @req FR-SVL-001
  - `final class ShutdownListener implements ServletContextListener` — constructor (RestApp app, int seconds)
    - `contextDestroyed(ServletContextEvent e): void` — first call only (AtomicBoolean): app.shutdown(seconds, TimeUnit.SECONDS); a failure is logged, never rethrown
- `NaruServe-servlet/src/main/java/com/snoworca/naruserve/servlet/NaruServeInitializer.java` — order of startup @req FR-SVL-001
  - `public class NaruServeInitializer implements ServletContainerInitializer` — from part 5
    - `onStartup(Set<Class<?>> classes, ServletContext ctx): void` — InitParams first, then create, start, addListener(new ShutdownListener(app, seconds)), then the servlet registration of part 5
- `docs/api/servlet.md` — port, lifecycle, Gson lookup, thread-total deviation, ignored and applied option lists, LAN-warning sentence @req FR-SVL-001, FR-SVL-008
- `src/test/java/com/snoworca/naruserve/docs/ServletDocsTest.java` — adds the methods of this part @req FR-SVL-001, FR-SVL-008

## Acceptance Contracts

- SDS-AC-1 (FR-SVL-001 AC-1): WHEN the context starts with naruserve.configurer THE SYSTEM SHALL build the app through the configurer and call app.listen(0) before any request, so onStart ran once, state() is RUNNING and a request is served → `AppStarter.start`, `NaruServeInitializer.onStartup`
- SDS-AC-2 (FR-SVL-001 AC-2): WHEN the context is destroyed THE SYSTEM SHALL run app.shutdown(seconds, SECONDS) once with the naruserve.shutdownTimeoutSeconds value (default 10), so onStop ran, state() is TERMINATED, adapter stop and release were called, shutdown returned within timeout plus the docs/api/lifecycle.md margin, and a second destruction does nothing → `ShutdownListener.contextDestroyed`
- SDS-AC-3 (FR-SVL-001 AC-3): WHEN boundPort is called before bind THE SYSTEM SHALL throw IllegalStateException, and after either bind return 0 without a thread or socket while ignoring host and port, with ServerHandle.port() 0 → `ServletAdapter.boundPort`, `ServletAdapter.bind`
- SDS-AC-4 (FR-SVL-001 AC-4): WHEN the application calls app.listen(8080) on an app built with a ServletAdapter THE SYSTEM SHALL bind nothing, run onStart and reach RUNNING through the same adapter path → `ServletAdapter.bind`
- SDS-AC-5 (FR-SVL-001 AC-5): WHEN GsonJsonCodec is on the web application's class path THE SYSTEM SHALL preset it so the configurer may replace it, and WHEN neither it nor Builder.jsonCodec exists THE SYSTEM SHALL fail startup with a ServletException naming com.snoworca.naruserve.gson.GsonJsonCodec and jsonCodec, with the module runtimeClasspath unchanged → `AppStarter.presetCodec`, `AppStarter.create`
- SDS-AC-6 (FR-SVL-001 AC-6): WHEN the configurer does not call Builder.logger THE SYSTEM SHALL keep the ConsoleLogger default, and a logger it sets is the one the app keeps → `AppStarter.create`
- SDS-AC-7 (FR-SVL-001 AC-7): WHEN an onStart callback fails THE SYSTEM SHALL fail context startup with a ServletException carrying it as cause, with no app thread left → `AppStarter.start`
- SDS-AC-8 (FR-SVL-001 AC-8): WHEN servlet.md is read THE SYSTEM SHALL say that the 451-thread total of the embedded engine does not apply and that threads are the container's plus at most maxSseStreams SSE threads → `ServletDocsTest.threadTotalDeviation`
- SDS-AC-9 (FR-SVL-008 AC-1): WHEN reflection inspects ServletAdapter THE SYSTEM SHALL find its own declared bind(ServerSettings, ExchangeHandler) that keeps maxSseStreams(3) and the settings' ErrorRenderer, whose custom body appears in the adapter's own 404 answer → `ServletAdapter.bind`, `ServletAdapter.settings`
- SDS-AC-10 (FR-SVL-008 AC-2): WHEN allowedHosts, bindAddress, maxWorkers(1) and maxHeaderSize(1024) are set THE SYSTEM SHALL serve a request with another Host and a normal header block unchanged → `ServletAdapter.bind`
- SDS-AC-11 (FR-SVL-008 AC-3): WHEN a JSON body exceeds jsonLimit, a form formLimit or a multipart request the app.multipart limits THE SYSTEM SHALL answer 413 with the standard body, because the adapter sets no container limit → `ServletAdapter.bind`
- SDS-AC-12 (FR-SVL-008 AC-4): WHEN servlet.md is read THE SYSTEM SHALL list the 13 ignored ServerOptions names and the applied names, each existing on ServerOptions or RestApp → `ServletDocsTest.ignoredAndAppliedOptions`
- SDS-AC-13 (FR-SVL-008 AC-5): WHEN a default app starts THE SYSTEM SHALL log no LAN warning, and servlet.md SHALL say that bindAddress and ServerHandle.address() describe the setting, not the container → `ServletDocsTest.lanWarningSentence`, `ServletAdapter.bind`

## Durable Rules

- ServletAdapter.bind opens no socket and boundPort is 0 - the container owns the port, and DefaultRestApp reads boundPort once
- GsonJsonCodec is found by reflection on the web application's class loader - the module runtimeClasspath must stay NaruServe-api only
