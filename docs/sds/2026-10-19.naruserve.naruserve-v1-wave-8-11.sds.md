- SDS-AC-2 (FR-REL-004 AC-2): WHEN a license is GPL-2.0, LGPL-3.0, AGPL-3.0 or unknown after the POM chain was searched (a parent-only license counts) THE SYSTEM SHALL fail, and pass Apache-2.0, MIT, BSD-3-Clause and a dual license → `LicenseCheck.verdict`, `LicenseCheck.licensesOf`
- SDS-AC-3 (FR-REL-004 AC-3): WHEN the committed file and dependency-graphs.txt (naruserve.depReport) differ THE SYSTEM SHALL fail naming each missing or extra dependency → `ThirdPartyLicenses.diff`
- SDS-AC-4 (FR-REL-004 AC-4): WHEN the release machine ran releaseLicenses THE SYSTEM SHALL carry command and result in the `licenses` run line → `RUN_NAMES`
