## Acceptance Contracts

- SDS-AC-1 (IR-COOKIE-001 AC-2): WHEN a Cookie is constructed THE SYSTEM SHALL start with path, domain, sameSite null, secure and httpOnly false and maxAge -1 → `Cookie.Cookie`
- SDS-AC-2 (IR-COOKIE-001 AC-5): WHEN a name is not an RFC 7230 token or a value holds a non cookie-octet outside one surrounding quote pair THE SYSTEM SHALL throw IllegalArgumentException naming name, value, path or domain → `Cookie.isValidValue`
- SDS-AC-3 (IR-COOKIE-001 AC-6): WHEN CookieFactoryHook loads THE SYSTEM SHALL hold only a private static final Method and AppIsolationTest SHALL find no mutable static field → `create`
- SDS-AC-4 (FR-COOKIE-001 AC-2): WHEN all attributes are set THE SYSTEM SHALL write exactly sid=abc; Path=/; Domain=example.com; Max-Age=3600; Secure; HttpOnly; SameSite=Lax → `serialize`
- SDS-AC-5 (FR-COOKIE-001 AC-4): WHEN maxAge is negative THE SYSTEM SHALL omit Max-Age and never write Expires → `serialize`
- SDS-AC-6 (FR-COOKIE-001 AC-5): WHEN a parsed cookie with value "x y" or a;b is added THE SYSTEM SHALL throw IllegalArgumentException and add no header → `addCookie`
- SDS-AC-7 (FR-COOKIE-001 AC-6): WHEN the response is committed THE SYSTEM SHALL throw IllegalStateException from addCookie like header → `addCookie`
- SDS-AC-8 (FR-COOKIE-002 AC-1): WHEN Cookie headers repeat a name THE SYSTEM SHALL return all pairs in header order and cookie(name) the first → `parse`
- SDS-AC-9 (FR-COOKIE-002 AC-4): WHEN pairs lack '=' or have a non-token name THE SYSTEM SHALL skip them without exception and keep quotes and %XX verbatim → `parse`
- SDS-AC-10 (FR-COOKIE-002 AC-2): WHEN getCookies is called twice THE SYSTEM SHALL return two distinct arrays, length 0 without a header → `getCookies`
- SDS-AC-11 (FR-COOKIE-002 AC-8): WHEN the surface tests run THE SYSTEM SHALL expect cookie, getCookies and addCookie added and the cookie return @Nullable → `cookie`
- SDS-AC-12 (IR-COOKIE-001 AC-7): WHEN Kotlin assigns c.maxAge, c.secure, c.isHttpOnly, c.sameSite and c.path THE SYSTEM SHALL compile without platform types → `Cookie`
