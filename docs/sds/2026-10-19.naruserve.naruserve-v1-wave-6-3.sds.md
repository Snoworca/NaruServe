## Acceptance Contracts

- SDS-AC-1 (FR-MULTIPART-003 AC-2): WHEN the media type before ';', trimmed and case-insensitive, is neither application/x-www-form-urlencoded nor multipart/form-data THE SYSTEM SHALL return EMPTY without touching BodyState while it is UNREAD, and call sharedParse (which throws BodyAlreadyConsumedException) once it is not → `formData`
- SDS-AC-2 (FR-MULTIPART-003 AC-1): WHEN an urlencoded pair has no '=' or is empty THE SYSTEM SHALL keep "a" as the value "" and skip the empty pair; a multipart text part SHALL decode as strict UTF-8 and answer 400 on malformed bytes → `firstText`
- SDS-AC-3 (FR-MULTIPART-003 AC-1): WHEN the body is urlencoded THE SYSTEM SHALL return EMPTY parts and no files, and form(name) the first decoded value → `FormData.parts`
- SDS-AC-4 (IR-MULTIPART-002 AC-3): WHEN parts() is called twice THE SYSTEM SHALL return the same unmodifiable list, while files(name) returns a fresh unmodifiable list per call → `FormData.parts`, `FormData.files`
- SDS-AC-5 (FR-MULTIPART-003 AC-5): WHEN a shared parse failed with 400 or 413 THE SYSTEM SHALL answer later accessor calls with BodyAlreadyConsumedException, the existing sharedParse rule → `formData`
