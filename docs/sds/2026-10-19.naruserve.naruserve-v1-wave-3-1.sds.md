## Acceptance Contracts

- SDS-AC-1 (IR-HTTP-001 AC-1): WHEN the attribute overloads are declared THE SYSTEM SHALL make the write overload return void and the read overload generic <T> @Nullable T taking Class<T>, so a literal null second argument resolves to the read overload → `Request.attribute`
- SDS-AC-2 (IR-HTTP-001 AC-2): WHEN status or header is called THE SYSTEM SHALL return the receiver, and send, html, stream, end and abort SHALL return void → `Response.status`, `Response.header`, `Response.send`
- SDS-AC-3 (IR-HTTP-001 AC-4): WHEN the nullable positions are listed THE SYSTEM SHALL annotate exactly the returns of query, header, lastEventId and attribute(key, type) and the parameters attribute(key, value) value and abort(error) with @Nullable → `Request.query`, `Request.header`, `Response.abort`
- SDS-AC-4 (IR-HTTP-001 AC-5): WHEN the Kotlin test runs THE SYSTEM SHALL route a request through the testFixtures TestApp harness and call every wave 3 Request and Response method from a Kotlin lambda → `Request`, `Response`
- SDS-AC-5 (IR-HTTP-002 AC-2): WHEN a Java lambda throws IOException or a Kotlin lambda { req, res -> } is assigned THE SYSTEM SHALL compile it as RouteHandler with no adapter type → `RouteHandler.handle`
- SDS-AC-6 (IR-HTTP-005 AC-5): WHEN RestApp methods are reflected THE SYSTEM SHALL find only get, post, put, patch, delete, head, options, route (three overloads) and routerPolicy → `RestApp`, `RestApp.routerPolicy`
- SDS-AC-7 (IR-HTTP-006 AC-1): WHEN a RouteBuilder method registers a handler THE SYSTEM SHALL return the same builder instance so calls chain → `RouteBuilder.get`, `RouteBuilder.delete`
- SDS-AC-8 (CON-ROUTE-006 AC-2): WHEN the routing reference rule is checked THE SYSTEM SHALL read every compiled com/snoworca/naruserve/routing class file and find no constant naming com/snoworca/naruserve/Request, Response, RouteHandler or RestApp → `Router`

## Durable Rules

- Public types in com.snoworca.naruserve avoid java.util.Optional, java.util.function, streams and java.nio.file — the animal-sniffer API 21 check and Android 5.0 users reject them.
- The routing package never references Request, Response, RouteHandler or RestApp — the router stays reusable with any handler type.
