## Acceptance Contracts

- SDS-AC-1 (IR-ROUTE-001 AC-3): WHEN Method is inspected by reflection THE SYSTEM SHALL expose only the static methods get, any, of plus enum built-ins, and no instance method named after an HTTP method → `Method`
- SDS-AC-2 (IR-ROUTE-001 AC-2): WHEN Method.of is called with a null array or a null element THE SYSTEM SHALL throw NullPointerException → `Method.of`
- SDS-AC-3 (IR-ROUTE-002 AC-4): WHEN the iterator of a MethodSet is asked to remove THE SYSTEM SHALL throw UnsupportedOperationException and the set SHALL be unchanged → `MethodSet.iterator`
- SDS-AC-4 (IR-ROUTE-002 AC-1): WHEN any combinator, with or except is called THE SYSTEM SHALL return a different MethodSet instance unless the members are unchanged and leave the receiver's members unchanged → `MethodSet.with`, `MethodSet.except`
- SDS-AC-5 (FR-ROUTE-001 AC-3): WHEN Method.any() is called before and after a router with TRACE and CONNECT enabled is built THE SYSTEM SHALL return equal sets without TRACE or CONNECT → `Method.any`
- SDS-AC-6 (IR-ROUTE-003 AC-1): WHEN a MethodSet is iterated THE SYSTEM SHALL yield members in Method.ordinal() order, and contains SHALL be the membership accessor → `MethodSet.contains`, `MethodSet.iterator`
- SDS-AC-7 (IR-ROUTE-003 AC-2): WHEN two MethodSets have the same members THE SYSTEM SHALL report equals true and equal hashCode, and toString SHALL list members in declaration order joined by ", " → `MethodSet.equals`, `MethodSet.toString`
- SDS-AC-8 (IR-ROUTE-003 AC-3): WHEN Kotlin code calls Method.get().post().except(Method.POST), `Method.GET in set` and a for loop over a set THE SYSTEM SHALL compile without backticks and without platform types → `MethodSet.contains`
- SDS-AC-9 (OPS-ROUTE-001 AC-2): WHEN docs/api/routing.md documents the accessors THE SYSTEM SHALL name contains, iterator and size exactly, with a Java and a Kotlin example and the note that Express has no counterpart → `methodSetAccessors`
- SDS-AC-10 (OPS-ROUTE-001 AC-3): WHEN docs/api/routing.md is updated THE SYSTEM SHALL keep the (미확정) markers on lines 71, 91 and 119 of the wave 1 text and the RouteBuilder use(middleware) marker, and add no new marker → `routingRules`
