## Acceptance Contracts

- SDS-AC-1 (FR-ENGINE-001 AC-1): WHEN reflection scans public classes of the module THE SYSTEM SHALL find no com.snoworca.tinyhttpd type in public or protected signatures → `TinyHttpdAdapter`
- SDS-AC-2 (FR-ENGINE-001 AC-2): WHEN an exchange asks for file transfer, eventStream or upgrade THE SYSTEM SHALL delegate to TinyHttpdFeatures, which throws UnsupportedOperationException naming the wave → `TinyHttpdFeatures`
- SDS-AC-3 (FR-ENGINE-001 AC-3): WHEN the class-reference scan reads the module THE SYSTEM SHALL find no TlsConfig and no tls(...) call → `configure`
- SDS-AC-4 (FR-ENGINE-001 AC-4): WHEN GET /a%20b?x=%41 arrives THE SYSTEM SHALL pass rawPath /a%20b and rawQuery x=%41, and null without '?' → `TinyHttpdExchange`
- SDS-AC-5 (FR-ENGINE-002 AC-1): WHEN settings carry the default THE SYSTEM SHALL call bindAddress(InetAddress.getByName("127.0.0.1")) and never getLoopbackAddress → `configure`
- SDS-AC-6 (FR-ENGINE-002 AC-4): WHEN the bind address is a host name THE SYSTEM SHALL add it to allowedHosts beside the configured names → `configure`
- SDS-AC-7 (FR-ENGINE-002 AC-6): WHEN start() throws BindException THE SYSTEM SHALL stop the half-built server, start no keeper thread and rethrow → `bind`
- SDS-AC-8 (FR-ENGINE-003 AC-2): WHEN maxRequestLineLength is n THE SYSTEM SHALL set maxRequestLineBytes n and inputBufferBytes max(8192, n + 2) → `configure`
- SDS-AC-9 (FR-ENGINE-003 AC-7): WHEN the builder is configured THE SYSTEM SHALL never call maxRequestBodyBytes or maxDrainBytes → `configure`
- SDS-AC-10 (FR-ENGINE-003 AC-8): WHEN non-default limits and timeouts are set THE SYSTEM SHALL read them back unchanged from config() → `config`
- SDS-AC-11 (FR-ENGINE-004 AC-1): WHEN defaults apply THE SYSTEM SHALL set maxWorkers 192, maxEventStreams 128, maxConnections 512, maxUpgradedConnections 128, maxConnectionsPerAddress 256 → `configure`
- SDS-AC-12 (FR-ENGINE-004 AC-3): WHEN workers and the zero-length queue are full THE SYSTEM SHALL let TinyHttpd answer the plain 503 with no access-log line → `bind`
