- SDS-AC-6 (OPS-HTTP-001 AC-5): WHEN app.md lists routerPolicy THE SYSTEM SHALL give one Java and one Kotlin block, and defaults.md SHALL name enableTrace/enableConnect without a marker → `routerPolicyRow`, `traceConnectRow`
- SDS-AC-7 (OPS-HTTP-002 AC-3): WHEN a block is not a top-level type THE SYSTEM SHALL wrap it in class DocExampleN with fields app, req, res and stub RouteHandler fields for the handler names the docs use, inside void example() throws Exception → `wrap`, `isTopLevelType`
- SDS-AC-8 (OPS-HTTP-002 AC-3): WHEN compiling THE SYSTEM SHALL run the system compiler in process with --release 8 and the test JVM's java.class.path, failing with each block's file, ordinal and diagnostics → `compile`
- SDS-AC-9 (OPS-HTTP-002 AC-4): WHEN a skip entry is defined THE SYSTEM SHALL require the file name, a selector (ordinal like #3 or the block's first line) and a reason naming the later-wave method or absent type → `SKIPS`
- SDS-AC-10 (OPS-HTTP-002 AC-6): WHEN a skip entry matches no block of its file THE SYSTEM SHALL fail the test naming the stale entry → `SKIPS`, `extractJavaBlocks`
- SDS-AC-11 (OPS-HTTP-002 AC-7): WHEN the run ends THE SYSTEM SHALL assert at least one compiled block from response.md and one from routing.md → `DocsExamplesCompileTest`
