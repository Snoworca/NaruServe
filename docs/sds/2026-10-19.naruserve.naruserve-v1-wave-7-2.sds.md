## Acceptance Contracts

- SDS-AC-1 (IR-WS-001 AC-2): WHEN ws registers THE SYSTEM SHALL wrap the handler in a WebSocketRoute and call webSocketRoute(path, route), so an invalid pattern throws what RoutePattern.parse throws for app.get → `DefaultRestApp.ws`, `WebSocketRoute`
- SDS-AC-2 (IR-WS-001 AC-3): WHEN ws or webSocket is called THE SYSTEM SHALL run requireConfigurable("ws") or ("webSocket") first and the null checks after it, so the IllegalStateException wins over a null argument after listen() → `DefaultRestApp.ws`, `DefaultRestApp.webSocket`
- SDS-AC-3 (IR-WS-001 AC-6): WHEN the configurer throws THE SYSTEM SHALL propagate it and keep every earlier setting, since it ran on copy() and nothing was swapped → `copy`
- SDS-AC-4 (IR-WS-001 AC-8): WHEN a duration is set THE SYSTEM SHALL convert with unit.toMillis (saturating) and compare 1000..3600000 or 1000..86400000 ms, so 999 MILLISECONDS and Long.MAX_VALUE DAYS are refused with the caller's own time and unit in the message → `pingInterval`, `idleTimeout`
- SDS-AC-5 (IR-WS-001 AC-7): WHEN allowedOrigins gets a null array or a null entry THE SYSTEM SHALL throw NullPointerException and keep the previous list; otherwise it SHALL store a defensive copy in the given order → `allowedOrigins`
- SDS-AC-6 (IR-WS-001 AC-6): WHEN freeze builds the dispatcher THE SYSTEM SHALL hand it webSocketOptions().copy(), so settings() for maxMessageSize 4096 and pingInterval 2 s gives 4096 and 2000 → `settings`, `webSocketOptions`
- SDS-AC-7 (IR-HTTP-008 AC-3): WHEN withHeader validates THE SYSTEM SHALL use checkHeader, the res.header rule, so a non-token name or a control char or char above U+00FF in the value is refused as well as CR and LF → `withHeader`, `checkHeader`
- SDS-AC-8 (IR-HTTP-008 AC-2): WHEN headers are stored THE SYSTEM SHALL keep an ArrayList of SimpleImmutableEntry so the exception stays Serializable, and headers() SHALL return Collections.unmodifiableList of it → `headers`
- SDS-AC-9 (IR-HTTP-008 AC-4): WHEN afterFailure takes the NEW branch and its error is an HttpException THE SYSTEM SHALL append its headers after headers.clear() and Content-Type; a failing onError handler's exception is the error then, so none are added → `DefaultResponse.afterFailure`
- SDS-AC-10 (IR-HTTP-008 AC-7): WHEN the exception carries Content-Length or Transfer-Encoding THE SYSTEM SHALL let prepare() remove them after they were appended and set its own Content-Length → `DefaultResponse.afterFailure`
