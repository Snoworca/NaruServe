- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/StaticPath.java` — static path checks on the raw path @req FR-STATIC-005
  - `static int check(String rawRelative): int` — 0 ok, 400 or 404
  - `static List<String> segments(String rawRelative): List<String>` — decoded segments after check ← StaticHandler
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/StaticHandler.java` — mount lookup, 301, SPA fallback and the 405 rule @req FR-STATIC-001, FR-STATIC-002, FR-STATIC-004
  - `final class StaticHandler` — mounts in registration order
    - `serve(DefaultRequest req, DefaultResponse res, boolean routeMethodMismatch): boolean` — true when it answered ← Dispatcher
    - `wouldServeGet(String rawPath): boolean` — file, index, listing or 301 hit, SPA excluded
    - `spaExcluded(String rawPath, List<String> extra): boolean` — /api and /ws always, segment boundaries

## Acceptance Contracts

- SDS-AC-1 (FR-STATIC-005 AC-1): WHEN a raw segment is checked THE SYSTEM SHALL decode it once and answer 400 if it is "." or "..", holds '/' or NUL, or still holds %2e, %2f or %00 (any case) so a second decode would give one of those → `check`
- SDS-AC-2 (FR-STATIC-005 AC-2): WHEN every segment passed SDS-AC-1 and a decoded segment starts with '.' THE SYSTEM SHALL answer 404; an empty segment (as in //assets) SHALL also answer 404 → `check`
- SDS-AC-3 (FR-STATIC-002 AC-5): WHEN no route matched and the path lies under a mount prefix THE SYSTEM SHALL run check for every method before the 405/404 decision → `serve`
- SDS-AC-4 (FR-STATIC-001 AC-6): WHEN a GET or HEAD names a directory without trailing '/' THE SYSTEM SHALL answer 301 with Location = raw path + "/" + ("?" + raw query when present) → `serve`
- SDS-AC-5 (FR-STATIC-001 AC-3): WHEN every mount missed THE SYSTEM SHALL try SPA fallback once, on the first registered mount with spaFallback(true) whose prefix matches → `serve`
- SDS-AC-6 (FR-STATIC-004 AC-1): WHEN SPA fallback is considered THE SYSTEM SHALL require GET or HEAD and an Accept header containing text/html case-insensitively; */* alone SHALL not qualify → `serve`
- SDS-AC-7 (FR-STATIC-004 AC-3): WHEN exclusions are matched THE SYSTEM SHALL compare the full raw request path with each prefix stripped of a trailing '/', as equal or followed by '/' → `spaExcluded`
- SDS-AC-8 (FR-STATIC-002 AC-1): WHEN a method other than GET or HEAD reaches serve and wouldServeGet is true THE SYSTEM SHALL answer 405 with Allow: GET, HEAD; otherwise return false so the router answer (404 or the route's 405) stands → `wouldServeGet`
- SDS-AC-9 (FR-STATIC-002 AC-3): WHEN a route matched the path but not the method THE SYSTEM SHALL call serve only for GET and HEAD and keep the route's own 405 and Allow when serve returns false → `fallback`
