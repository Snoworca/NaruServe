## Acceptance Contracts

- SDS-AC-1 (IR-STATIC-001 AC-1): WHEN the prefix ends in '/' and is not "/" THE SYSTEM SHALL strip it, and the same prefix registered twice SHALL keep both mounts in registration order like two Express static middlewares → `addStatic`
- SDS-AC-2 (IR-STATIC-001 AC-1): WHEN dir does not exist at registration THE SYSTEM SHALL accept it; the canonical root is taken at listen and a missing root serves nothing (404) → `addStatic`
- SDS-AC-3 (IR-STATIC-001 AC-2): WHEN index gets an empty name or one holding '/', or spaExclude gets a prefix not starting with '/' THE SYSTEM SHALL throw IllegalArgumentException → `DefaultStaticOptions`
- SDS-AC-4 (IR-STATIC-001 AC-3): WHEN a resolver method cannot read the path THE SYSTEM SHALL throw IOException, FileNotFoundException for a missing or refused path → `open`
- SDS-AC-5 (IR-STATIC-002 AC-1): WHEN privateFor or publicFor gets a negative amount THE SYSTEM SHALL throw IllegalArgumentException; equals, hashCode and toString SHALL follow getHeaderValue → `publicFor`, `getHeaderValue`
- SDS-AC-6 (IR-STATIC-002 AC-3): WHEN cache is called on a committed response THE SYSTEM SHALL throw IllegalStateException like header → `cache`
