### Files

- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/FileResourceResolver.java` — the one built-in ResourceResolver, java.io only @req FR-STATIC-006
  - `final class FileResourceResolver implements ResourceResolver` — no java.nio.file reference
    - `FileResourceResolver(File canonicalRoot, boolean allowSymlinks)` — root canonicalised once by the caller at listen ← StaticMount
    - `static FileResourceResolver forFile(File file): FileResourceResolver` — root = canonical file.getAbsoluteFile().getParentFile() ← DefaultResponse
    - `open(String path): InputStream` — check, open, re-check; closes and throws FileNotFoundException on a failed re-check
    - `length(String path): long` / `etag(String path): String` / `modified(String path): long`
    - `linkFree(File f): boolean` — each component's canonical path equals parent canonical + name
    - `afterCheck(@Nullable Runnable hook): void` — package-private instance test hook between check and open
- `NaruServe-api/src/main/java/com/snoworca/naruserve/internal/DefaultMimeTypes.java` — built-in table, per-app registry and lookup @req FR-STATIC-007
  - `final class DefaultMimeTypes implements MimeTypes` — one per DefaultRestApp
    - `static final Map<String, String> BUILT_IN` — unmodifiable; exactly the docs/api/static.md table
    - `register(String ext, String type): MimeTypes` — strips one leading '.', lower-cases ext (Locale.ROOT)
    - `lookup(String fileName, Map<String, String> mount): String` — mount, app, BUILT_IN, application/octet-stream; text/* gets ; charset=UTF-8
- `build.gradle` — every test task gets systemProperty sun.io.useCanonCaches=false @req FR-STATIC-006

## Acceptance Contracts

- SDS-AC-1 (FR-STATIC-006 AC-2): WHEN the component check runs THE SYSTEM SHALL walk from the canonical root to the target and refuse when any component's getCanonicalPath() differs from its parent's canonical path + separator + name → `linkFree`
- SDS-AC-2 (FR-STATIC-006 AC-3): WHEN allowSymlinks is true THE SYSTEM SHALL skip linkFree but still refuse a canonical path outside the canonical root → `open`
- SDS-AC-3 (FR-STATIC-006 AC-4): WHEN open succeeded THE SYSTEM SHALL recompute the canonical path and linkFree and, on any change, close the stream and throw FileNotFoundException, answered 404 → `open`, `afterCheck`
- SDS-AC-4 (FR-STATIC-006 AC-5): WHEN res.file names a symlink, a directory or a missing file THE SYSTEM SHALL throw FileNotFoundException from forFile's resolver, mapped to HttpException(404) by DefaultResponse → `forFile`
- SDS-AC-5 (FR-STATIC-006 AC-1): WHEN the path is only checked for containment THE SYSTEM SHALL compare canonical paths with the root path plus separator, so /root2 is not under /root → `open`
- SDS-AC-6 (FR-STATIC-006 AC-6): WHEN the Gradle test tasks run THE SYSTEM SHALL pass -Dsun.io.useCanonCaches=false and the swap test SHALL assert the property → `FileResourceResolver`
- SDS-AC-7 (FR-STATIC-007 AC-1): WHEN the extension is taken THE SYSTEM SHALL use the text after the last '.' of the file name; a name without '.' or ending in '.' SHALL get application/octet-stream → `lookup`
- SDS-AC-8 (FR-STATIC-007 AC-4): WHEN a registered type already has parameters or a charset THE SYSTEM SHALL send it unchanged; only a bare text/* type gains ; charset=UTF-8 → `lookup`
