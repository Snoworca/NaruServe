## Acceptance Contracts

- SDS-AC-1 (OPS-APP-001 AC-1): WHEN app.md is updated THE SYSTEM SHALL document builder(), the AppFactory SPI and the exception create() throws when no module provides it (type and message as FR-APP-001 fixes them), and that non-daemon server threads keep the JVM alive (enforced by the TinyHttpd adapter in wave 5) → `builderSection`, `serverHandleNote`
- SDS-AC-2 (OPS-APP-001 AC-6): WHEN an app.md line mixes a wave 4 marker with a ws marker THE SYSTEM SHALL split it so the ws return-type and ws callback-name markers stay on their own lines → `callbackNote`
- SDS-AC-3 (OPS-APP-001 AC-2): WHEN middleware.md and routing.md are updated THE SYSTEM SHALL state RouteBuilder.use as the multi-middleware form, D-126 warning plus end(), the onError chain stopping at the first handler that starts the response, the STOPPING → 503 standard-body row, and the full-queue 503 as TinyHttpd plain text → `errorSection`, `routeUseNote`
- SDS-AC-4 (OPS-APP-001 AC-7): WHEN a wave 4 decision is written THE SYSTEM SHALL put its reason in one adjacent sentence → `routeUseNote`, `builderSection`
- SDS-AC-5 (OPS-APP-001 AC-6): WHEN AppDocsTest runs THE SYSTEM SHALL fail if a REMOVED phrase still carries (미확정) on its line or a KEPT phrase lost its marker → `AppDocsTest.REMOVED`, `AppDocsTest.KEPT`
- SDS-AC-6 (OPS-APP-001 AC-3): WHEN lifecycle.md is updated THE SYSTEM SHALL name registerExternal, AppStartException, the start gate (wait, or 503 + Connection: close on failure) and the STARTING shutdown timeout that keeps the pending stop, all without marker → `AppDocsTest`
- SDS-AC-7 (OPS-APP-001 AC-4): WHEN logging.md is updated THE SYSTEM SHALL give the access log line `<method> <path> <status>[ aborted][ <n>ms][ in=<i> out=<o>][ rid=<id>]`, tag NaruServe, ./logs 5 MiB × 5, naruserve.log names and context.getFilesDir() → `AppDocsTest`
- SDS-AC-8 (OPS-APP-001 AC-5): WHEN express-migration.md is updated THE SYSTEM SHALL drop the multi-middleware, req.path() prefix, 500 code and 404 body markers and keep the Router and cors markers → `AppDocsTest.KEPT`
- SDS-AC-9 (OPS-HTTP-003 AC-8): WHEN HttpDocsTest runs THE SYSTEM SHALL cite OPS-HTTP-003 and no longer require the RouteBuilder.use marker in routing.md → `HttpDocsTest`
- SDS-AC-10 (OPS-ROUTE-003 AC-3): WHEN RoutingDocsTest runs THE SYSTEM SHALL cite OPS-ROUTE-003 and assert no line of routing.md contains (미확정) → `RoutingDocsTest.noMarkerRemains`
- SDS-AC-11 (OPS-HTTP-004 AC-3): WHEN a block is wrapped THE SYSTEM SHALL add the spi and java.util.concurrent imports and the stub fields ctx (ApplicationContext), auth (Middleware), myAdapter (HttpAdapter), myCodec (JsonCodec) → `DocsExamplesCompileTest.IMPORTS`, `DocsExamplesCompileTest.wrap`
- SDS-AC-12 (OPS-HTTP-004 AC-4): WHEN a block assumes an app-defined type such as UserService or Database THE SYSTEM SHALL skip it with that type named as the reason → `DocsExamplesCompileTest.SKIPS`
- SDS-AC-13 (OPS-APP-002 AC-1): WHEN the skip list is updated THE SYSTEM SHALL remove every entry whose reason is a wave 4 member and re-point any still-failing one to the later-wave member it needs → `DocsExamplesCompileTest.SKIPS`
- SDS-AC-14 (OPS-APP-002 AC-2): WHEN a skip entry's block compiles THE SYSTEM SHALL fail naming the entry, in addition to the stale-selector check → `DocsExamplesCompileTest.SKIPS`
