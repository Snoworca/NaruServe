## Acceptance Contracts

- SDS-AC-1 (FR-HTTP-013 AC-1): WHEN header sets a name already present in another case THE SYSTEM SHALL replace that entry keeping one header of the name, as Express res.set does → `DefaultResponse.header`
- SDS-AC-2 (FR-HTTP-014 AC-1): WHEN a body writer runs and no Content-Type header is set (compared case-insensitively) THE SYSTEM SHALL add text/plain; charset=UTF-8 for send(String), text/html; charset=UTF-8 for html and application/octet-stream for send(byte[]) → `DefaultResponse.send`, `DefaultResponse.html`
- SDS-AC-3 (FR-HTTP-014 AC-4): WHEN the stream copy runs THE SYSTEM SHALL read with an 8192-byte buffer and write each chunk to the exchange OutputStream in order → `DefaultResponse.runTransfer`
- SDS-AC-4 (FR-HTTP-014 AC-5): WHEN the copy ends by success, read or write failure, or abort THE SYSTEM SHALL close the input exactly once through a compare-and-set guard → `DefaultResponse.runTransfer`, `DefaultResponse.abort`
- SDS-AC-5 (FR-HTTP-014 AC-7): WHEN stream is called THE SYSTEM SHALL set Content-Type to the argument, commit with unknown length, enter STREAMING and return; the Dispatcher runs runTransfer on the adapter thread after the handler returns → `DefaultResponse.stream`
- SDS-AC-6 (FR-HTTP-014 AC-6): WHEN end runs on a non-bodyless response THE SYSTEM SHALL commit with Content-Length: 0 and the status and headers set so far → `DefaultResponse.end`
- SDS-AC-7 (FR-HTTP-015 AC-4): WHEN header gets a name or value containing CR or LF THE SYSTEM SHALL throw IllegalArgumentException and keep the header list unchanged; the state check runs first → `DefaultResponse.header`
- SDS-AC-8 (FR-HTTP-015 AC-1): WHEN abort runs before any commit THE SYSTEM SHALL leave isCommitted false, set ABORTED and abort the exchange without writing a status → `DefaultResponse.isCommitted`, `DefaultResponse.abort`
- SDS-AC-9 (FR-HTTP-015 AC-3): WHEN abort runs in COMPLETED or ABORTED THE SYSTEM SHALL return without calling the exchange → `DefaultResponse.abort`
- SDS-AC-10 (FR-HTTP-016 AC-2): WHEN status, header or any body writer runs in COMMITTED, STREAMING, COMPLETED or ABORTED THE SYSTEM SHALL throw IllegalStateException naming the state and change nothing → `DefaultResponse.status`, `DefaultResponse.send`
- SDS-AC-11 (FR-HTTP-016 AC-4): WHEN a read failure happens during runTransfer THE SYSTEM SHALL set ABORTED, call exchange.abort() and close the input, without rethrowing to the adapter → `DefaultResponse.runTransfer`
- SDS-AC-12 (FR-HTTP-017 AC-1): WHEN bodyless() is true for 204 or 304 THE SYSTEM SHALL commit with length 0, add no Content-Length header and drop the body bytes → `DefaultResponse.bodyless`, `DefaultResponse.send`
- SDS-AC-13 (FR-HTTP-017 AC-3): WHEN the request is HEAD THE SYSTEM SHALL send the Content-Length the body would have had and write zero body bytes; a HEAD stream closes the input without copying → `DefaultResponse.bodyless`, `DefaultResponse.stream`
- SDS-AC-14 (FR-HTTP-018 AC-2): WHEN the response is COMPLETED THE SYSTEM SHALL keep isCommitted and every Request read accessor working without exception → `DefaultResponse.isCommitted`, `DefaultResponse.state`
