## Acceptance Contracts

- SDS-AC-1 (FR-APP-002 AC-1): WHEN two apps are built in one JVM with different routes, middleware, loggers and onStart THE SYSTEM SHALL keep every registration in instance fields so each app answers, runs and logs only its own → `DefaultRestApp`
- SDS-AC-2 (FR-APP-002 AC-2): WHEN the reflection scan walks com.snoworca.naruserve and .internal THE SYSTEM SHALL find no non-final static field and no static mutable collection, allowing only constants and never-written private static final arrays → `AppLifecycle`, `DefaultRestApp`
- SDS-AC-3 (FR-APP-002 AC-3): WHEN a registration or configuration method runs in STARTING, RUNNING, STOPPING or TERMINATED THE SYSTEM SHALL throw IllegalStateException whose message contains the method name and the state name, before any argument is recorded → `AppLifecycle.requireConfigurable`
- SDS-AC-4 (FR-APP-002 AC-4): WHEN any non-static RestApp method returning RestApp or a RouteBuilder registration method runs THE SYSTEM SHALL call requireConfigurable first; logger(), state() and route(String) do not call it → `AppLifecycle.requireConfigurable`, `DefaultRestApp.route`, `DefaultRouteBuilder`
- SDS-AC-5 (FR-APP-002 AC-5): WHEN the route table is frozen while the state is still NEW THE SYSTEM SHALL reject registrations through the same guard, keeping FR-HTTP-008 AC-5 green → `AppLifecycle.requireConfigurable`, `DefaultRestApp.freeze`
- SDS-AC-6 (FR-APP-009 AC-1): WHEN two threads call listen(0) on a NEW app THE SYSTEM SHALL let only the compareAndSet winner proceed; the loser and any later listen get IllegalStateException → `AppLifecycle.beginStart`
- SDS-AC-7 (FR-APP-009 AC-2): WHEN listen runs THE SYSTEM SHALL do in order STARTING, onStart callbacks in registration order, freeze, one bind, RUNNING, return → `DefaultRestApp.listen`
- SDS-AC-8 (FR-APP-009 AC-3): WHEN the freeze throws RoutingConfigException THE SYSTEM SHALL throw it from listen after onStart ran and before bind → `DefaultRestApp.listen`, `DefaultRestApp.freeze`
- SDS-AC-9 (FR-APP-009 AC-4): WHEN bind returns THE SYSTEM SHALL return a ServerHandle whose port() is adapter.boundPort() → `DefaultRestApp.listen`
- SDS-AC-10 (FR-APP-009 AC-5): WHEN a request reaches the gated handler in STARTING THE SYSTEM SHALL block it on the start gate and dispatch it only after markRunning → `GatedExchangeHandler.handle`, `AppLifecycle.markRunning`
- SDS-AC-11 (FR-APP-009 AC-6): WHEN bind throws after a held request THE SYSTEM SHALL release the gate with a failure and answer the held request 503, Connection: close, standard error body, with no middleware, handler or onError → `GatedExchangeHandler.handle`
- SDS-AC-12 (FR-APP-009 AC-7): WHEN TestApp.start runs THE SYSTEM SHALL build the app with RestApp.builder().httpAdapter(adapter).jsonCodec(new StubJsonCodec()) and call listen(0) once → `TestApp.start`, `StubJsonCodec`
- SDS-AC-13 (FR-APP-009 AC-8): WHEN a unit test binds DefaultRestApp.dispatcher() without listen THE SYSTEM SHALL dispatch with no gate; only listen wraps it in GatedExchangeHandler → `DefaultRestApp.dispatcher`, `GatedExchangeHandler`
