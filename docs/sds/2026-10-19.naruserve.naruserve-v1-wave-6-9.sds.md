## Acceptance Contracts

- SDS-AC-1 (FR-ENGINE-010 AC-2): WHEN offset is negative, length is negative or offset + length exceeds the file length THE SYSTEM SHALL throw IllegalArgumentException before the response starts → `TinyHttpdExchange.sendFile`
- SDS-AC-2 (FR-ENGINE-010 AC-2): WHEN the file shrinks during the copy THE SYSTEM SHALL throw IOException (EOF before length bytes) and leave the exchange to the abort path → `sendFile`
- SDS-AC-3 (FR-ENGINE-010 AC-2): WHEN sendFile commits THE SYSTEM SHALL go through the exchange commit, so a second start throws IllegalStateException like commit → `TinyHttpdExchange.sendFile`
