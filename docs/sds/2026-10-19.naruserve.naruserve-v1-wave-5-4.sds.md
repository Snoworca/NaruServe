## Acceptance Contracts

- SDS-AC-1 (IR-ENGINE-001 AC-2): WHEN server(...) is never called THE SYSTEM SHALL freeze the documented defaults, 127.0.0.1 and no allowed hosts → `freeze`
- SDS-AC-2 (IR-ENGINE-001 AC-3): WHEN a setter gets a value outside its range or null THE SYSTEM SHALL throw IllegalArgumentException or NullPointerException naming the setting and range → `maxHeaderSize`
- SDS-AC-3 (IR-ENGINE-001 AC-7): WHEN the RestApp surface test runs THE SYSTEM SHALL expect the wave 4 set plus server, trustProxy, jsonCodec and jsonLimit → `server`
- SDS-AC-4 (IR-ENGINE-002 AC-1): WHEN an adapter implements only the wave 3 bind THE SYSTEM SHALL receive one call through the default method → `bind`
- SDS-AC-5 (IR-ENGINE-002 AC-2): WHEN listen(port) runs THE SYSTEM SHALL call bind(ServerSettings, handler) once with the frozen values → `start`
- SDS-AC-6 (IR-ENGINE-002 AC-4): WHEN the app logger throws THE SYSTEM SHALL hand adapters a SafeLogger so settings.logger() never throws → `freeze`
- SDS-AC-7 (IR-ENGINE-002 AC-5): WHEN render(421) is called twice THE SYSTEM SHALL return two bodies with code HTTP_421, message Misdirected Request and different requestIds → `renderer`
- SDS-AC-8 (FR-ENGINE-008 AC-2): WHEN trustProxy(true) and X-Forwarded-For lists several hops THE SYSTEM SHALL return the trimmed left-most entry → `remoteAddress`
- SDS-AC-9 (FR-ENGINE-008 AC-3): WHEN only Forwarded is present or the left-most entry is blank THE SYSTEM SHALL keep the exchange values → `isSecure`
- SDS-AC-10 (FR-ENGINE-002 AC-3): WHEN the bind address is outside 127.0.0.0/8, ::1 and localhost THE SYSTEM SHALL log one warn naming the address before bind → `start`
- SDS-AC-11 (FR-ENGINE-004 AC-2): WHEN maxConnections < maxWorkers + maxSseStreams THE SYSTEM SHALL throw IllegalStateException in the freeze, after onStart, before bind → `start`
- SDS-AC-12 (FR-ENGINE-005 AC-2): WHEN the error path writes status 408 THE SYSTEM SHALL add Connection: close and message Request Timeout → `renderer`
