### Target: 0.10.0

**Goal:** Complete epic #46 and issues #47-65 with independent parallel lanes, requirement-backed TDD, up to 3 test-sufficiency review/fix rounds stopping on first pass, existing dependencies and Java Pattern, preserved extensions/WS, final whole-suite review, bilingual API docs, commit/push and Maven 0.10.0 publication.

### Target: central-0.9.0

**Goal:** Make the ten modules Maven Central ready at version 0.9.0: lowercase artifactIds (naruserve, naruserve-api, ..., naruserve-android), sources and javadoc JARs, full POM metadata, and a verified local staging repository build/central-staging; signing and the Central Portal upload are a separate, user-confirmed step.

### Target: android-module

**Goal:** Make NaruServe the general default (API + TinyHttpd + Gson exposed as api + console logger, usable on any JDK), build NaruServe-kotlin on it, and add a minimal NaruServe-android AAR (NaruServe + Logcat logger + INTERNET permission) built with AGP when an Android SDK is present.

### Target: start-api

**Goal:** Add RestApp.start(int, Configurer<RestApp>) as a one-call static entry point with ServerHandle.url/shutdown, a start log line and a JVM-only shutdown hook, without changing any listen rule.

### Target: tinyhttpd-3

**Goal:** Make the build resolve TinyHttpd 3.0.0 (com.snoworca:tinyhttpd-core and tinyhttpd-websocket through includeBuild) and record commit c000eb1 as the verified checkout in build, docs and SRS.

### Target: api-usability

**Goal:** Resolve every child issue of epic #21 with requirement-backed TDD, independent review and per-issue integration into origin/main.
