# Intake — epic Snoworca/NaruServe#20

Source: GitHub issue #20 and its 19 sub-issues (read with `gh issue view`). Spec: `object.md`. API contract: `docs/api/`.

## Epic body

## 목표

`docs/api/`에 정리한 공개 API 계약을 구현한다. Express.js 사용자가 Java 8 / Kotlin에서 바로 쓸 수 있는 경량 HTTP 서버 라이브러리를 Android 5.0(API 21)과 일반 JVM에서 같은 API로 제공한다.

- 사양서(SSOT): `object.md`
- API 계약: `docs/api/README.md` 와 하위 문서
- 프로젝트 규칙: `CLAUDE.md` (Java 8 bytecode, API 21 animal-sniffer 검사, Gson 2.14.0 고정, Gradle 8.14.3)
- HTTP 엔진: TinyHttpd (`Snoworca/TinyHttpd`, NanoHTTPD 포크)

## 단계 (object.md §19)

| 단계 | 범위 | Gate |
|---|---|---|
| 기반 | 모듈·빌드·테스트 기반 | `./gradlew build` 통과 |
| P0 | Method/Router, Request/Response, Middleware, Context/Lifecycle, Logging SPI | Java 8·API 21 빌드, T01–T08 |
| P1 | TinyHttpd 어댑터, Gson JSON, Cookie, 오류, AccessLog | T09–T12, T33–T40, T48 |

| P5 (선택) | Servlet 어댑터 | 별도 테스트 |

- 각 하위 이슈의 인수 테스트(T-ID)가 자동 테스트로 존재하고 통과한다.
- `NaruServe-api`와 Android 대상 모듈은 animal-sniffer API 21 검사를 통과한다.
- `(미확정)` 항목은 사용자에게 묻지 않고 구현하면서 정한다. 사양서(`object.md`)와 어긋나지 않고 Express 사용자에게 가장 자연스러운 쪽을 고른다. 정한 내용은 `docs/api/`에서 표시를 지우고 확정 내용으로 고치며, PR/커밋에 결정 사유를 남긴다.
- 공개 API에는 `@Nullable`/`@NonNull`을 붙이고, Kotlin 컴파일 테스트로 확인한다.
