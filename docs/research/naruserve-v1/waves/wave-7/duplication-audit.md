# Wave 7 duplication audit (stage 7)

Stage 7 merged one lane (8141421..6856cb4). Wave 7 adds the WebSocket upgrade, sessions, bounded send queues and sender executor, the Server-Sent Events stream and drain, deadline-aware shutdown participants, HttpException headers, the TinyHttpd upgrade and event-stream classes, and the socket, fixture and docs tests that cover them. There are thirty-five duplicates after the w7-D-020 revision: eleven touch main code and twenty-four are test-only (including testFixtures and the docs helpers). Twenty-six near-misses are recorded as distinct. Two wave-6 precedents are revisited: the int range helper of the option classes now has a byte-identical copy in the new code, and `repeat(char, n)` has a third copy, so both are recorded as duplicates.
