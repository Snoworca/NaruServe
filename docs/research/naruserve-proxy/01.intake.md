## Summary

The requester (an internal service team moving an API gateway onto NaruServe) cannot build a transparent reverse proxy on the 0.11.0 public `Request`/`Response` API: the raw body cannot be read, request header names cannot be enumerated, and a response cannot carry repeated header lines. They ask for:

- **Request A — raw access API in `NaruServe-api`:** `req.bodyStream()` / `bodyStream(long)` with an app-wide `rawBodyLimit`, `req.headerNames()`, `req.rawHeaders()`, `res.append(name, value)`, `req.isFromTrustedProxy()`, `res.onAbort(Runnable)`, `res.relay(InputStream, long)`, public `HttpHeaderValues.isFieldValue`, and moving `BodyTooLargeException` to the public package with a 413 mapping.
- **Request B — `NaruServe-proxy` module:** `Proxy.to(url)` returning an immutable `Middleware` with options (timeouts, retries, header add/remove, strip prefix, preserve host, body limit, concurrency limit, Location rewrite, SSL socket factory), backed by a hand-written HTTP/1.1 client on sockets that keeps Java 8 and Android API 21 compatibility and uses only the public API from request A.

The document fixes acceptance criteria AC-A1..AC-A14 and AC-B1..AC-B34, and records the requester's recommended option for 22 open decisions (§5).

## Feasibility notes carried from the pre-run review

Checked against the 0.11.0 sources before the run started (recorded in the Alfred wiki, `2026-11-14.naruserve-proxy-feasibility.md`):

- SPI `HttpExchange.headers()` already returns received order with duplicates; TinyHttpd `Exchange.getHeaderEntries()` keeps case and order.
- `DefaultResponse` stores headers in a `List`, so `append` is direct; the internal `sendBody`/`startBody` already take a length; `begin()` applies `defaultCache`, which `relay` must bypass.
- `HttpExecution` already registers `exchange.onAbort`; both built-in adapters implement `onAbort`.
- `Request.methodToken()` exists and `originalUrl()` includes the query.
- `BodyTooLargeException` is internal; `StandardErrors.statusOf` maps only `HttpException`; `refusePathInstallable` rejects path-mounted `Installable`; `DefaultRequest` has a package-private `bodyStream()` that must be renamed.
- `object.md` lists HTTP client and proxy as "선택/향후", which matches a separate optional module.
- No existing SRS requirement covers raw body, header enumeration or a proxy.
