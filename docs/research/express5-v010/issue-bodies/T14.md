## 문제와 변경 결과

SSE 외 일반 지연 요청도 컨테이너에서 끝까지 유지하고 정확히 완료한다.

## 선행 작업

#50, #58

## 수정 소유 경계

`servlet-adapter`

- `NaruServe-servlet/src/main/`
- `NaruServe-servlet/src/test/`

## 인수 기준

- [ ] service 반환 이후 일반 deferred 응답/오류/timeout/abort를 처리한다.
- [ ] 일반 요청과 SSE의 자원 한도와 executor를 혼동하지 않는다.
- [ ] raw URI와 컨테이너 선행 거부 경계를 실제 Servlet환경에서 대조한다.
- [ ] in-flight 집계·shutdown·async completion·stream ownership의 중복/누수를 방지한다.
- [ ] 지원 Servlet 컨테이너 설정에서 선언한 raw-path 코퍼스가 실제로 통과해야 한다. 선행 거부를 기록하는 것만으로 통과 처리하지 않으며 지원 구성과 불가능한 구성을 설계에서 구별한다.

## 검증

- embedded Servlet3.1 async integration
- disconnect/timeout/shutdown races
- raw URI container policy evidence
