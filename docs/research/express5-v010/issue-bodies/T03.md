## 인수 기준

- [ ] raw pathname 매칭 뒤 캡처를 한 번 디코딩하고 wildcard 목록·optional absent를 표현한다.
- [ ] 미선언/선택/빈 값의 Java 및 Kotlin 계약과 paramInt 같은 편의 함수의 결과를 명시한다.
- [ ] path/url/baseUrl/originalUrl 대응 뷰를 설정·복원한다.
- [ ] body 소비상태, JSON 캐시, attributes, services, requestId, uploads를 계층마다 재생성하지 않는다.
- [ ] params/path의 복원은 oracle의 Router/mount 경계에서 수행한다. 모든 next 반환마다 이전 params를 무조건 복원하지 않으며 같은 Router의 after-next 관찰값도 검증한다.

## 검증
