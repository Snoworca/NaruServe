## 인수 기준

- [ ] next는 다음 일치 항목, route skip은 같은 Route의 나머지, router skip은 현재 마운트를 구분한다.
- [ ] use에서 route skip을 호출한 동작도 oracle과 맞춘다.
- [ ] 응답 완료만으로 다음 항목을 자동 실행하지 않는다. 다만 res.end 뒤 명시 next는 oracle대로 뒤 handler/use를 실행할 수 있고 기존 completed-response guard로 무조건 거부하지 않는다. 반복 next도 실제 trace와 대조한다.
- [ ] 상위 middleware로 복귀할 때 올바른 params/mount view와 before/after 의미를 유지한다.
- [ ] T06에서는 mount-frame continuation 계약과 synthetic frame 단위 router skip을 검증하고 T07에서 실제 nested mount end-to-end를 완성한다.
- [ ] 같은 Router 안의 before/after-next와 mounted Router 종료 시점의 상태 복원을 구분해 실제 trace와 맞춘다.
