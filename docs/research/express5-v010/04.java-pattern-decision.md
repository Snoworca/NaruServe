# Java Pattern route decision

Status: explicit user decision, superseding the earlier ECMAScript RegExp engine proposal. Requirements remain authoritative in docs/spec/. No runtime implementation is claimed.

User instruction:

> 아닙니다. 자바의 정규식으로 갑시다. 그것까지 자바 스크립트로 맞출 필요 없죠.

Regular-expression route inputs use java.util.regex.Pattern and Java regex semantics. Reproducing JavaScript RegExp syntax, flags, g/y lastIndex or ECMAScript-engine capture quirks is outside the requested compatibility boundary. JNI, QuickJS, Rhino and a new ECMAScript parser/VM are removed from this work plan.

The remaining common HTTP-routing goal stays aligned with Express 5: string-path grammar, ordered registration, Route boundaries, mounts, continuation/error flow, parameter hooks and HTTP defaults. Existing NaruServe extensions and WebSocket contracts remain protected. Path alternatives still preserve selection order. Java regex integration receives its own Java/Kotlin and Java8/API21 checks, including documented search-vs-full-match behavior, capture extraction and decoding, Pattern flags, and per-match Matcher isolation. Exact public API and capture access details remain ordinary design work before SRS/TDD implementation; no untested Android named-group API is assumed.

Express differential fixtures cover the agreed common behavior and patterns with demonstrated shared semantics. Java-specific regex syntax and outcomes are checked against the Java contract, not counted as unexplained Express failures. The compatibility boundary is recorded before fixture generation and described in both language versions of the final documentation.

Historical engine research (03.regexp-engine-research.md and evidence/regexp/) remains evidence of the earlier investigation, not a current implementation requirement. Q-REGEX is resolved. Q-EXT concerning writes in ../TinyHttpd remains unanswered.

Affected existing interfaces: IR-HTTP-005 and IR-HTTP-006; changes to their routing contracts are authored through the permitted wave SRS stage before implementation.
