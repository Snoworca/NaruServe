# RegExp research evidence

These programs and logs reproduce exploratory engine comparisons. They are not production implementation tests or a claim that NaruServe is compatible. Source archive/JAR hashes and official URLs are in source-manifest.json. Local tool paths in the historical invocation records describe the observed environment; rerunning elsewhere requires obtaining those exact inputs and replacing local paths. No third-party binaries or source trees are vendored here.

The engine decision remains open. Java Pattern, sampled Rhino, and sampled QuickJS have concrete mismatches. Android/JNI has not been validated. See ../../03.regexp-engine-research.md.
