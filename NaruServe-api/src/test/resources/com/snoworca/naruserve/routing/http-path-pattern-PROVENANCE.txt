FR-ROUTE-018 — pinned HTTP string compiler source provenance

The matching corpus is derived from pillarjs/path-to-regexp v8.4.2,
https://github.com/pillarjs/path-to-regexp/tree/v8.4.2
src/cases.spec.ts, src/index.ts (grammar and regex safety algorithm).
The TSV contains raw-value oracle results from path-to-regexp 8.4.2 match(),
with decode: value => value and end/sensitive/trailing from each case.
Only string patterns with the default delimiter and no encodePath hook are included.
TokenData, path arrays and path generation are outside this string compiler API.
257 vectors; generated with Node v22.22.0 (Unicode 16.0).
Columns: base64(pattern), end, sensitive, trailing, base64(input), matches,
base64(matchedPath), captures (base64(name):base64(value),...;...).
All strings use UTF8. Empty capture values are significant.
